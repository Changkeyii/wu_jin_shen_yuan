# 百级成长与五级档装备罐

## 最终规则

- 人物最高100级；装备和罐子使用5、10、15……100级，共20档。
- 许愿每次独立等概率抽取符合等级条件的罐子。下限为人物等级向上取5级档，最高100级：35级抽35～100，36级抽40～100，99和100级只抽100级。原品质权重、角色概率和保底次数保持不变。
- 罐子取得时固定等级，后续升级不会改变库存罐子的等级。开启产生同等级装备；人物等级不足也能开罐并保留装备，达到穿戴等级后使用。新手5级装备从1级可穿。
- 普通玩法新掉落按人物等级和来源进度限制，向下取5级档，最高100；明确指定等级的罐子和GM邮件奖励按指定档生成。
- 开罐前检查整批空位，最多6个；任一生成失败则整批失败，罐子和库存保持原状。套装罐产出对应套装的史诗或神话装备。
- 罐子可回收碎片，需确认；每个罐子的碎片为等级/5乘品质系数（神器1、传说2、史诗4、神话8，其他罐2）。

## 成长终点

首页目标依次为20/40/60/80/100级、同一套装100级史诗及以上的12个不同部位、同套装神话、通关第150层章节Boss。通关要求最高到达层大于150，仅到达150不算完成。毕业后仍可冲层、强化升星及优化词条。

100级后经验每100万兑换1碎片，每个UTC+8自然日最多100碎片；未满100万的余数持久化，当日超上限整份经验不跨日累积。不增加永久战斗属性。古代祭祀击杀永久加成到100%停止增长，已经超过该值的历史加成保留。

## 旧存档兼容

角色存档版本升到11。首次迁移保留历史等级与经验记录，人物现等级显示最高100；旧最高层产生的角色基础战力作为固定历史下限保留，后续冲层不继续扩大该下限。

旧装备记录原等级，现等级对齐5级档并封顶100，实际属性、强化、升星、投入和经济价值保留；历史装备继续允许穿戴。新版装备的手动穿戴、自动穿戴、换装决定、撤销和存档恢复均校验人物等级。旧无等级罐保留库存，以旧版100级罐开启；新的通用道具奖励和邮件领取生成符合领取时人物等级的随机档，指定档奖励保持指定等级。

## 实现与界面合同

沿用现有服务端领域事务、快照/增量协议、持久化和客户端界面结构。成长状态单独深拷贝，避免战斗结算修改输入存档。回收沿用请求超时和连接代次保护，断线前弹窗与迟到回调不能影响重连请求。

按 ui-interface-maker 的边界要求复用原素材，不新增临时背景。首页英雄板目标区域为x596/y254/w270/h52；背包详情内部有效区域x42～899/y34～392，回收按钮x748/y294/w150/h46，位于原详情板内。使用原字体、按钮和提示框；没有增加素材依赖。
