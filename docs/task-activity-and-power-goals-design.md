# 任务、活动与战力目标系统设计草案

状态：**讨论稿，暂不实施**  
适用项目：无尽深渊  
最后更新：2026-08-05

---

## 1. 设计目标

当前游戏已经具备放置挂机、离线收益、装备掉落、强化、升星、交易行、章节与楼层基础，但玩家缺少明确的“现在该做什么”和“为什么要继续提升战力”。

本系统的目标是建立完整的目标循环：

```text
任务告诉玩家现在做什么
→ 目标卡告诉玩家为什么做
→ 战力门槛告诉玩家还差多少
→ Boss 验证养成结果
→ 新章节和新玩法解锁
→ 无尽模式与排行榜提供长期追求
→ 活动提供周期性变化
```

本阶段只讨论产品结构，不实施代码。

---

## 2. 三种核心玩法定位

### 2.1 普通深渊：稳定成长线

普通深渊是主要的放置和离线资源来源：

```text
挂机
→ 获得金币、经验、装备、碎片
→ 装备 / 强化 / 升星 / 交易
→ 战力提升
→ 推进更高楼层
```

定位：

- 可以自动推进；
- 支持离线收益；
- 奖励稳定；
- 失败成本低；
- 主要服务于长期养成；
- 不以排行榜竞争为核心。

### 2.2 Boss 深渊：阶段检验点

Boss 深渊用于回答：

```text
当前养成是否足够？
装备构筑是否合理？
```

每个章节可以拥有一个章节 Boss：

```text
第 1 章 Boss
第 2 章 Boss
第 3 章 Boss
```

Boss 页面显示：

- Boss 名称；
- Boss 特性；
- 推荐战力；
- 当前战力；
- 战力差距；
- 首通奖励；
- 再次挑战奖励；
- 下一章节解锁内容。

Boss 不应只是普通敌人的血量放大版，至少应具备一个简单机制，例如：

- 高防御；
- 高暴击；
- 周期性狂暴；
- 低生命强化；
- 针对特定属性的抗性或弱点。

### 2.3 无尽模式：极限挑战与排行榜

无尽模式不替代普通挂机，而是展示玩家的极限战力：

```text
普通深渊 = 稳定成长
Boss 深渊 = 阶段检验
无尽模式 = 极限挑战
```

无尽模式可以采用：

- 最高通关层数排名；
- 同层通关时间作为次级排序；
- 每周或赛季重置记录；
- 记录个人最高层、本周最高层和历史最高层；
- 与普通深渊掉落隔离，避免成为基础资源刷取漏洞。

无尽奖励建议以以下内容为主：

- 称号；
- 头像框；
- 展示徽章；
- 外观；
- 少量高级资源；
- 赛季荣誉。

## 3. 任务系统

任务系统负责回答：

```text
玩家现在应该做什么？
```

建议分为五类。

### 3.1 主线任务

主线任务推动系统解锁和成长阶段：

```text
认识首页功能
进入深渊
开始自动挂机
装备第一件装备
到达第 5 层
完成第一次强化
击败章节 Boss
进入 Boss 深渊
解锁无尽模式
完成一次无尽挑战
```

主线奖励：

- 系统解锁；
- 固定成长装备；
- 强化材料；
- 市场货币；
- 新章节入口；
- 新玩法入口。

主线任务不应主要使用“挂机很久”或“击杀大量敌人”这类只消耗时间的条件。

### 3.2 成长任务

成长任务教玩家理解养成：

```text
装备 1 件装备
完成一次快捷装备
装备 3 件装备
强化装备到 +1
强化装备到 +5
升星一次
完成一次自动装备
设置一次自动处置策略
```

### 3.3 日常任务

每天提供 3～5 个轻量目标。挂机期间完成的战斗应自动计入，不应把放置游戏变成强制手动打卡：

```text
完成 1 次普通深渊挑战
领取 1 次挂机收益
完成 1 次装备强化
完成 1 次 Boss 挑战
浏览 1 次市场
```

日常奖励应是成长加速，不应成为不完成就无法正常推进的惩罚。

### 3.4 周常任务

周常任务连接高级内容：

```text
挑战章节 Boss 3 次
完成无尽模式 1 次
获得 3 件史诗以上装备
完成 2 次市场交易
强化装备 5 次
累计提升一定战力
```

Boss、无尽、排行榜和市场更适合放在周常，而不是全部塞入每日任务。

### 3.5 成就任务

成就任务永久存在、不重置：

```text
到达第 100 层
击败第一个章节 Boss
首次进入无尽模式
完成一次无伤 Boss
获得完整套装
完成 10 次交易
进入排行榜前 100
```

奖励建议以称号、展示徽章、头像框、收藏和少量资源为主。

## 4. 活动系统

活动系统负责回答：

```text
为什么这一周值得回来？
```

初期建议四类活动。

### 4.1 资源活动

低理解成本、容易轮换：

```text
强化返还提升
掉落率提升
碎片额外掉落
市场手续费降低
```

### 4.2 挑战活动

围绕成绩而不是单纯奖励倍率：

```text
Boss 竞速周
无尽冲层周
限定词缀挑战
低战力通关挑战
```

### 4.3 收集活动

与图鉴结合：

```text
收集指定部位装备
收集指定套装
收集 Boss 战利品
收集限定掉落标记
```

### 4.4 赛季活动

周期建议 2～4 周：

```text
赛季最高层
赛季 Boss 评分
赛季战力成长
赛季装备收集
赛季交易成就
```

赛季奖励以荣誉、展示和少量高级资源为主。初期不建议先做复杂的付费通行证。

## 5. 战力门槛设计

不建议所有系统都只使用一个总战力数字。推荐使用三层结构：

```text
解锁门槛
→ 推荐战力
→ 实际挑战验证
```

### 5.1 解锁门槛

决定玩家何时能看到或进入内容：

- 前置章节 Boss；
- 前置楼层；
- 主线任务；
- 玩家等级；
- 教学完成。

例如：

```text
Boss 深渊：完成第 10 层
无尽模式：击败第 3 章 Boss
市场高级区域：完成市场教学并达到第 20 层
```

### 5.2 推荐战力

告诉玩家当前是否适合挑战，但不一定禁止尝试：

```text
当前战力：12,400
推荐战力：15,000
差距：-2,600
```

颜色建议：

```text
绿色：推荐挑战
黄色：有风险
红色：明显不足
```

### 5.3 实际挑战验证

最终结果由战斗实际决定。合理构筑的玩家可以略低于推荐战力挑战成功，避免总战力成为唯一答案。

建议：

```text
普通深渊：主要按楼层推进，不用战力硬锁
Boss 深渊：楼层解锁 + 推荐战力 + 允许尝试
无尽模式：按实际通关层数和成绩排名
高级系统：章节 / 楼层解锁，战力作为风险提示
```

### 5.4 门槛展示模板

所有锁定内容应说明三件事：

```text
如何解锁
当前差距
解锁后能得到什么
```

示例：

```text
章节 Boss：深渊守门者
解锁条件：完成第 10 层
推荐战力：18,500
当前战力：15,200
还差：3,300
解锁奖励：章节装备、稀有碎片、新玩法入口
```

## 6. 首页目标卡

首页除了资源和属性，还需要一个“下一目标”卡片。首页只显示一个最重要的主目标，完整任务列表放在任务中心。

建议显示：

```text
下一目标：击败第 1 章 Boss
当前战力：12,400
推荐战力：15,000
还差：2,600
建议：强化 2 件装备
```

目标卡应动态变化：

```text
新玩家：完成新手引导
成长阶段：到达下一章节 Boss
战力不足：推荐强化或换装
Boss 已解锁：挑战章节 Boss
Boss 已完成：解锁无尽模式
无尽已开放：冲击本周最高层
```

目标卡点击后应直接导向相关功能：

- Boss 目标 → Boss 深渊；
- 装备差距 → 装备页；
- 构筑缺口 → 市场；
- 楼层目标 → 刷宝页；
- 任务目标 → 任务中心。

## 7. 首页、任务、活动、挑战的关系

推荐的产品结构：

```text
首页
├─ 当前目标卡：现在最值得做什么
├─ 任务 / 活动入口：完整目标列表
└─ 战力和资源摘要

任务中心
├─ 主线
├─ 成长
├─ 每日
├─ 每周
└─ 成就

活动中心
├─ 当前活动
├─ 活动任务
└─ 活动奖励

挑战中心
├─ 章节 Boss
├─ 无尽模式
└─ 排行榜
```

首页不应塞入所有任务条目；它只负责给出方向。

## 8. 长期目标循环

```text
首页查看下一目标
→ 普通深渊挂机获取资源
→ 装备 / 强化 / 升星 / 交易
→ 战力提升
→ 挑战章节 Boss
→ 解锁新章节、新系统和新活动
→ 进入无尽模式
→ 冲击排行榜
→ 获得赛季荣誉和特殊奖励
→ 回到首页查看下一目标
```

玩家每个行为都应有清晰理由：

```text
为什么挂机？获得成长资源。
为什么装备？提高属性和战力。
为什么强化？突破 Boss 推荐战力。
为什么交易？补齐构筑缺口。
为什么打 Boss？推进章节并解锁玩法。
为什么打无尽？证明极限并参与排行榜。
```

## 9. 重要产品决策

后续实现前需要先确认：

1. 普通深渊是否作为唯一稳定资源主线；
2. Boss 深渊是一次性首通、每日挑战还是周期挑战；
3. 无尽模式是否按周或赛季重置；
4. 无尽模式是否共享普通深渊装备和战力；
5. 排行榜按层数、时间、战力，还是多榜并存；
6. 排行榜是跨常驻服分片还是单分片；
7. 排行榜奖励是否影响主经济；
8. 战力目标是否展示“还差几件装备 / 几级强化”；
9. 内容解锁按等级、楼层、Boss 首通，还是三者组合；
10. 市场是成长补强工具，还是独立经济与社交玩法；
11. 活动是否优先做 Boss、无尽、收集和资源轮换；
12. 首页目标卡是否始终只显示一个主目标。

## 10. 推荐优先级

### P0：确定目标架构

```text
普通深渊 = 稳定成长
Boss 深渊 = 阶段检验
无尽模式 = 极限挑战与排行榜
```

### P1：确定首页目标卡

```text
当前战力
下一目标
推荐战力
差距
前往按钮
```

### P2：确定任务中心分类

```text
主线 / 成长 / 每日 / 每周 / 成就
```

### P3：确定活动轮换规则

先做挑战、收集、资源轮换，不急于做复杂付费活动。

### P4：再拆分实现

```text
TaskEngine
ActivityEngine
GoalSummaryView
BossChallenge
EndlessMode
Leaderboard
```

## 11. 当前结论

任务系统解决“玩家现在要做什么”。

首页目标卡解决“玩家为什么做”。

战力门槛解决“玩家还差多少”。

Boss 解决“成长是否有效”。

无尽模式和排行榜解决“长期追求什么”。

活动系统解决“这一周为什么值得回来”。

最终产品主线应从：

```text
挂机等待
```

升级为：

```text
看目标
→ 挂机成长
→ 调整养成
→ 挑战 Boss
→ 解锁新内容
→ 冲击无尽和排行榜
```
