# 离线收益修复与10%产出

离线经验、金币及装备掉落统一使用 `GameBalance.OFFLINE_RATE = 0.10`，各自只折算一次。累计上限24小时，15分钟领取门槛保留；在同一参考楼层、装备和挂机效率下，离线一天约等于在线2小时24分钟。在线有效训练24小时到100级的规则不变，满级精通经验也按10%产生，再沿用500经验换1碎片、每日300碎片上限。

## 离线时间为0的原因

`RewardEngine.AccrueOffline` 返回的是运行时状态变更，云提交类型为 `none`。登录服务原先用“是否产生云提交”判断是否接收状态，导致算出的离线秒数被丢弃。现在按照实际时长和最后活跃时间变化接收状态，保留旧存档作为下一次云版本保护写入的基准。登录不增加阻塞云写，领取或原有断线检查点负责保存。

同一实例中因未确认断线存档而保留的会话，重连按真实断线区间累计。存档尚在写入或确认时，新增时长等待该写入结束后合并。已在线的连接替换不算离线；旧代次回调不能删除新会话。确认事务回滚时保留原运行时离线秒数和锁定报价，避免重新读取旧云记录又将它们清零。

## 背包与领取

按一次固定的掉落舍入结果，选择背包能容纳的最大结算时段；金币、经验和掉落都只处理该时段，剩余时长继续保留。背包完全满时暂不生成报价。冻结后在线战斗不会改变报价，领取会合并到最新状态。

领取前再次检查主背包和临时掉落空间，空间不足则拒绝本次领取，保留报价和离线时间，整理后原报价可重试。成功领取不丢弃装备，临时掉落仍受原120件上限约束。章节首领保底的无掉落次数按10%折算，避免离线品质保底以在线速度推进。

## 验证范围

`tests/offline_delivery.lua` 使用真实云网关、存档仓库、服务层和客户端适配器，覆盖登录0秒根因、899/900秒边界、24小时上限、跨实例换服、重复预览/领取、保存失败重试、成功但回调丢失、失败但回调丢失、旧回调、断线存档中重连、在线连接替换、满背包和领取前空间变化。成长回归核对24小时离线等价于8640秒在线训练，并覆盖满级边界和小数经验。Maker开发构建与代码模拟由开发流程检查，正式服发布及实机验收由项目方完成。
