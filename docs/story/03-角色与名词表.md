# 角色与名词表

> 本表为剧情名词的**统一字典**。新剧情引用任何名词前，先查本表；新增名词必须登记，避免一词多名。

---

## 一、角色

| 名称 | 身份 | 状态 | 说明 |
|------|------|------|------|
| **主角（失落者）** | 前代登塔者，失忆 | 现役登塔者 | 手持赤焰枪刃（残刃）。第三章证实曾主动抹去自己的记忆。名字未知（悬念）。 |
| **塔灵** | 万灵塔的意识投影 | 常驻 | 引导者、保管者。不说谎，但可以不说全。声音如风过回廊。 |
| **缄默守门人** | 第 1 章守塔人 | 已镇守 | 忘了姓名，只记得职责。执残刃。 |
| **断誓将军** | 第 2 章守塔人 | 已镇守 | 曾立下誓言，誓言比盔甲更沉重。 |
| **镜中旧我** | 第 3 章守塔人 | 已镇守 | 以镜为形的存在，映射登塔者的软弱与过去。 |
| **万灵铸魂者** | 第 4 章守塔人 | 已镇守 | 以记忆为火的锻造者。 |
| **初代守塔人** | 第 5 章守塔人 | 已镇守 | 第一个决定留下的人。问出「塔存在的意义」。 |
| **无面之影 / 旧影** | 深渊投影 | 章节试炼 | 外形取自主角失去记忆前的轮廓。 |
| **「门」中的存在** | 塔底之物 | 被封印 | 曾被误认为怪物，实为被关进塔里的存在（悬念）。 |

## 二、势力 / 群体

| 名称 | 说明 |
|------|------|
| **万灵** | 自愿进入塔中、以记忆维持封印的守护者们（不是塔的名字）。 |
| **守塔人** | 每 10 层一位的前代强者，职责是镇守该层封印。 |
| **登塔者** | 被塔选中或被迫进入塔中的灵魂。 |
| **深渊** | 世界的伤口，吞噬记忆、名字、形体。 |
| **尘乡** | 残存人类聚居的最后大陆，高墙与灯火隔绝深渊。 |

## 三、地点

| 名称 | 说明 |
|------|------|
| **万灵塔** | 世界的封印核心，层数未知，顶部连向深渊。 |
| **塔底** | 「门」的封印所在，任何文字不记载其全貌。 |
| **塔顶** | 下一段深渊的入口（第五章揭示）。 |
| **无名回廊** | 未命名章节的通用场景名。 |

## 四、核心名词

| 名称 | 定义 | 备注 |
|------|------|------|
| **塔底之物 / 「门」** | 塔封印的存在 | 不是怪物，是被关进去的存在。封印由万灵记忆维持。 |
| **残刃** | 主角武器（赤焰枪刃）的初始形态 | 与守门人残刃形成暗示性对照。 |
| **记忆碎片** | 击败守塔人后获得的剧情道具 | 对应 memory 段落。 |
| **失落的名字** | 主角被抹去的身份 | 主线悬念，贯穿全书。 |
| **万灵的记忆** | 封印的燃料 | 塔核心衰弱的直接原因。 |
| **数据符文 / 全息投影** | 塔的科技化视觉语言 | 赛博朋克 × 暗黑奇幻混合风格的载体。 |
