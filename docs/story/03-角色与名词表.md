# 角色与名词表

> 本表是独立剧情模式「万灵记忆」及全项目剧情文案的统一字典。
> 人物不是功能标签。每人至少承担一种对「被记住」的回答；详见 `16-主题意象与人物内涵.md`。

---

## 一、核心角色

| 名称 | 身份 | 说明 | 主题负担 |
|---|---|---|---|
| **主角 / 失落者 / 你** | 现役登塔者、记忆调查者 | 主动封锁根名与关键记忆。剧情正文不强制替玩家命名。 | 资格与责任：找回的不是无罪的自己，而是重新被询问的资格。 |
| **第零见证者** | 主角旧日职责 | 记录所有选择但不替任何人选择；第 28 章确认。 | 空席：见证者若坐上决定席，见证就会变成统治。 |
| **塔灵** | 万灵塔意识投影 | 引导、保管与校验记录。不说谎，但受权限与封印规则限制。 | 完美记忆的孤独：它记得一切，因此最不懂改变主意为何正当。 |
| **初代守塔人** | 旧封印建立者 | 维护现行封印，不是反派；认为替代方案成熟前必须先守住今天。 | 先保住今晚：合理、沉重，但不能永远否决未来。 |
| **守灯人弥娅** | 尘乡主灯维护者 | 现世活人，务实且拒绝被救世叙事代言。 | 具体生活：任何方案若不能让今晚的灯还亮着，就只是更漂亮的封印。 |
| **界门意志** | 旧迁移命令形成的系统意志 | 没有毁灭欲，持续执行“让所有人通过”的失控命令。 | 失控的拯救：爱所有人，却看不见每一个人。 |

## 三、核心群体与地点

| 名称 | 定义 |
|---|---|
| **万灵** | 自愿进入塔中、以记忆维持封印的个体集合；不是统一思想或资源池。 |
| **守塔人** | 旧日强者与职责承担者。剧情战斗通常面对其记录或映像。 |
| **尘乡** | 人类最后大陆，也是万灵塔的现实锚。 |
| **深渊** | 世界伤口及身份侵蚀现象的总称。 |
| **无名潮** | 迁移意识失去边界后彼此覆盖形成的群体。 |
| **万灵塔** | 封印核心、避难所与身份保存设施。 |
| **记忆界** | 可保存意识与知识的层面，第 17 章后公开。 |
| **界门 / 门** | 连接现实与记忆界的旧通道；前期只称“门”。 |
| **尘乡主灯** | 尘乡现实锚核心，由弥娅维护。 |

## 四、核心名词

| 名称 | 定义 |
|---|---|
| **万灵记忆** | 独立剧情模式；通过固定 Campaign 关卡调查记忆锚点。 |
| **剧情章 / Stage / Node** | 独立剧情进度单位，不等于塔层、房间或章节 Boss。 |
| **塔中残响** | 登塔过程中的轻量世界观演出，与独立剧情进度分离。 |
| **根名** | 连接完整身份记录的核心索引；主角主动封锁。 |
| **赤焰枪刃 / 残刃** | 第零见证者的记录武器。 |
| **赤焰映像** | 许愿池中的战斗记录，不是另一位同名真人。 |
| **记忆锚点** | 保存人物、地点或共同现实的稳定记录。 |
| **旧约** | 万灵加入封印时的契约；有自愿进入，缺少可执行退出机制。 |
| **众证协议** | 通过知情、有限、可撤回的多方见证保存身份边界的替代封印。 |
| **归名** | 从无名潮中分离个体并恢复稳定身份；必须尊重本人意愿。 |
| **战斗映像** | 塔保存的技能与行为记录，不等于本人完整复活。 |

## 五、统一用词

1. “剧情章”只表示 Campaign 章节，禁止写“剧情第 X 章对应第 X0 层”。
2. 登塔演出统一称“塔中残响”或“塔内记忆”，不作为主线通关条件。
3. 第 17 章前优先使用“门”，不公开界门与迁移事故。
4. 第 29 章前不在玩家文本中出现“众证协议”。
5. 主角公开称谓使用“你”“失落者”“持刃者”；根名未定稿前禁止编造。
6. 许愿池角色应使用“战斗映像”说明，避免真人、武器与映像混淆。
7. 写角色时先问：他赞成“被记住”，还是在保护“不被汇总”的权利？两者都没有的角色只是过场。
8. 禁止用失忆洗白旧日签名；禁止把万灵写成单纯受骗者；禁止把初代写成必须被打倒的暴君。
