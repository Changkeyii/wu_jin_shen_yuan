# 剧情接入规范

> 本文档描述剧情内容如何接入游戏系统，以及文档与代码的同步规则。

---

## 一、剧情内容存放位置

- **剧情权威文本**：`docs/story/`（本文档集）——所有台词、设定、大纲的唯一定稿处。
- **运行时台词**：`scripts/shared/StoryCatalog.lua`（章节剧情）、`scripts/client/TutorialController.lua`（新手引导台词）——**从 docs 同步而来，不得与 docs 冲突**。
- 修改台词流程：先改 docs → 再同步代码（或反向同步后回写 docs），二者必须一致。

## 二、系统映射

| 系统 | 代码位置 | 对应文档 |
|------|----------|----------|
| 章节剧情（10 层一章） | `StoryCatalog.lua`（CHAPTERS：opening/boss/memory） | `02-章节剧情大纲.md` |
| 新手引导状态机 | `TutorialEngine.lua`（服务端，step 1~5） | `01-新手序章剧情.md` |
| 新手引导演出 | `TutorialController.lua`（客户端：CG/对话/引导提示） | `01-新手序章剧情.md` |
| 世界观/角色/名词 | 无代码（纯设定） | `00-世界观设定.md`、`03-角色与名词表.md` |

## 三、新手引导（TutorialEngine）步骤说明

| step | 剧情章节 | 触发条件 | 奖励/掉落 |
|------|----------|----------|-----------|
| 1 | 塔灵唤醒 | 首次击杀（在线战斗） | 保底掉落白装武器 + 白装防具 |
| 2 | 战斗的馈赠 | 穿戴成功 | 推进 |
| 3 | 物尽其用 | 分解成功 | 推进 |
| 4 | 百炼成钢 | 强化成功 | 推进 |
| 5 | 初试锋芒 | 登塔推进一层 | 完成：金币 5000 + 碎片 50 + 全随机罐 ×2 |

- 服务端在 `PlayerProfileService.Attach` 中每次登录重置教程（测试期每次进入触发）。
- 正式版「终身一次」：移除 Attach 中的重置即可（`TutorialEngine.Reset` 调用点）。

## 四、章节剧情（StoryCatalog）接入规则

1. 新增章节：在 `CHAPTERS` 追加 `{ id, floor, title, opening, boss, memory }`。
2. 三层结构：`opening`（进入章节）、`boss`（BOSS 战前）、`memory`（BOSS 战后记忆碎片）。
3. 章节号 = `floor / 10`；未手写章节自动使用「第 N 章·无名回廊」。
4. 每章至少推进一条主线悬念（见 `02-章节剧情大纲.md` 写作规范）。

## 五、对话演出（客户端）

- 新手引导对话：`TutorialController.STEP_LINES`（标题 + 台词数组 + 引导文案 + 目标页面）。
- 章节剧情对话：`GameplayDialogsController.ShowStoryGate` → CommonPromptDialog（story 类型，多页）。
- 演出原则：
  - 台词 2~3 句/段，短句、意象化；
  - 对话确认后进入引导（操作提示条），不拦截页面操作；
  - 序章期间屏蔽首页弹窗（`FaceSlapController.isBlocked` 已接入）。

## 六、文档维护规则

1. **新增剧情前**：先查 `03-角色与名词表.md`，确认名词统一。
2. **新增剧情时**：先更新 `docs/story/` 对应文档，再实现代码。
3. **剧情修改后**：docs 与代码必须同步，提交信息注明「story: ...」。
4. **禁止**：在代码里临时改台词而不更新 docs（会导致前后不连贯）。
