# 独立剧情模式接入规范

> **硬规则**：剧情模式与登塔模式完全独立。
> 剧情模式使用 `campaign` 领域；登塔继续使用 `floor / maxFloor / position`。

---

## 一、现有系统边界

### 保留为登塔专属

- `scripts/shared/StoryCatalog.lua`：现有塔中残响目录。
- `pendingStoryGate`：登塔暂停与塔中演出。
- `StoryBrowserController`：现有塔内记忆回顾。
- `PlayPresentation`：登塔路线与战斗表现。
- `TowerRules / FloorRoute / currentMonster`：登塔战斗。

上述模块不得作为独立剧情模式进度真源。

### 独立剧情模式应新增

```text
scripts/shared/CampaignCatalog.lua
scripts/shared/CampaignDefinitions.lua
scripts/shared/CampaignRewardPolicy.lua
scripts/server/domain/CampaignEngine.lua
scripts/server/domain/CampaignCombatEngine.lua
scripts/server/commands/CampaignCommands.lua
scripts/client/CampaignController.lua
scripts/client/CampaignView.lua
scripts/client/CampaignDialogueController.lua
scripts/client/CampaignBattlePresentation.lua
```

第一期可合并客户端文件，但服务端 `campaign` 领域必须独立。

## 二、解锁与进度

剧情入口在序章完成后开放：

```text
tutorial.completed == true
→ 解锁 Campaign 第一章第一关
```

后续解锁只依赖：

```text
前置剧情 Stage 已通关
必要的剧情选择已完成
内容版本允许访问
```

禁止依赖或修改：

```text
floor
maxFloor
position
FloorRoute
塔章节 Boss
塔掉落 pity
塔里程碑
```

## 三、推荐服务端状态

```lua
campaign = {
    contentVersion = 1,
    highestUnlockedChapter = 1,
    currentStageId = "main:c01:a",

    completedStages = {
        ["main:c01:a"] = {
            clearCount = 1,
            bestStars = 3,
            firstClearClaimed = true,
            clearedAt = 0,
        },
    },

    completedChapters = {},
    activeStage = nil,
    activeDialogue = nil,
    activeBattle = nil,
    choices = {},
    claimedRewardKeys = {},
    challengeProgress = {},
}
```

### 稳定 ID

```text
campaignId: main
chapterId: main:c01
stageId: main:c01:a
nodeId: main:c01:a:intro
battleId: campaign:<runId>:<nodeId>
rewardKey: campaign:stage:main:c01:c:first
```

所有 ID 发布后不可复用给其他内容。

## 四、服务端命令

建议：

```text
Campaign.StartStage
Campaign.AdvanceDialogue
Campaign.AdvanceBattle
Campaign.ClaimStageReward
Campaign.SelectChoice
Campaign.AbandonStage
```

客户端只能提交意图与稳定 ID，不得提交：

```text
伤害
敌人血量
是否胜利
奖励数量
装备品质
经验
下一节点
塔层
```

服务端从 `CampaignCatalog` 验证节点关系、敌人、奖励与解锁。

## 五、剧情战斗

剧情战斗使用 `campaign.activeBattle`，不得复用：

```text
state.currentMonster
state.hp 作为剧情实例生命
CombatEngine.BeginBattle 的塔层敌人生成
TowerRules.MonsterStats
GameEngine 的楼层胜利结算
IdleRuntimeService 的挂机 tick
```

可复用纯能力：

- 玩家权威属性计算；
- 大数值运算；
- 暴击、吸血等纯战斗公式；
- 攻击时间线理念；
- 通用经验、货币、装备入库；
- 服务端 revision、持久化和 delta。

剧情开始、推进、胜败和领奖都使用持久化 `PlayerProfileService:Apply`，保证断线恢复与奖励幂等。

## 六、状态管线

实现 `campaign` 时必须同步更新：

1. `StateFactory`：新账号默认状态。
2. `StateNormalizer`：旧账号迁移与状态清理。
3. `GameStateContracts`：持久化、快照、delta 字段白名单。
4. `GameStateBoundarySchemas`：严格状态 schema。
5. `GameStatePersistence`：持久化字段。
6. `GameStateWire`：快照与 delta。
7. `PlayerTransition`：完整 campaign 领域变更检测。
8. `GameEventSchema`：独立 `campaign_*` 事件。
9. `GameStateAdapter`：客户端完整替换 `campaign` 领域。

旧玩家的塔中剧情观看状态不得自动迁移成 Campaign 已通关；最多开放第一章或给予回顾资格。

## 七、客户端页面

独立页面流：

```text
剧情入口
→ 八卷地图
→ 章节列表
→ Stage 详情
→ 剧情/战斗
→ 首通结算
→ 下一 Stage 解锁
```

新增页面 ID 建议：`campaign`。

`play` 继续只表示登塔。离开剧情页面时只清理剧情表现，不影响登塔挂机状态；离开登塔也不改变剧情 Stage。

## 八、经验与奖励

剧情经验调用服务端通用升级逻辑，但数值来自 `CampaignRewardPolicy`，不使用塔层公式。

原则：

- 前两卷让玩家在 60–90 分钟达到 Lv.12–15。
- 第四卷完成约 Lv.20–22；当且仅当账号等级达到 Lv.20 且深渊引导已完成时，独立深渊系统开放异变档。Campaign 只显示引导和解锁提示，不直接改写 `abyss` 状态。
- 主线完成约 Lv.35–38，不直接保证 Lv.40。
- 剧情固定追赶装备默认以 Rare 为主；如配置更高品质，服务端必须按当前登塔品质解锁裁剪。未满足品质门槛时改发同槽位 Rare、碎片或延期兑换凭证，不能绕过塔品质规则。
- 不直接发 Epic / Myth 塔系装备。
- 不修改市场按塔层限制购买装备等级的规则。
- 剧情战斗默认不计入 `floor_advance`、塔怪、塔精英或塔 Boss 任务。

如任务需要统计剧情，新增：

```text
campaign_stage_clear
campaign_chapter_clear
campaign_star_earned
campaign_elite_clear
```

## 九、序章衔接

序章 step 5 仍是功能介绍；看完后完成序章并发放既有赠礼。随后塔灵开启独立剧情入口“万灵记忆”。

剧情模式不替代登塔。玩家可以：

- 先推剧情快速升级；
- 去登塔刷装备；
- 去深渊定向补强；
- 返回剧情继续下一关。

这是一种互补关系，而不是互锁。

## 十、终局选择

第 40 章终局需要专用 Campaign 选择状态，不可复用普通对话完成：

```lua
campaign.endingChoice = {
    choiceId = "main:choice:ending",
    available = {
        seal = true,
        erase = true,
        witness = false,
    },
    selected = nil,
}
```

规则：

- 服务端计算可用选项；
- 客户端只提交选项 ID；
- 不可逆选择二次确认；
- 不设倒计时和默认选项；
- 重连恢复未完成选择；
- 不由广告、付费、排行榜或真人社交解锁。

## 十一、验收清单

- [ ] Campaign 进度不读取或修改 `floor / maxFloor / position`。
- [ ] 剧情战斗不写 `currentMonster`。
- [ ] 剧情胜利不触发塔里程碑、塔 pity 或塔任务。
- [ ] 登塔挂机与剧情 Stage 互不清空。
- [ ] 断线重连恢复当前剧情对话或战斗。
- [ ] 首通奖励具备持久化幂等键。
- [ ] 推荐战力是软提示，不是塔层门槛。
- [ ] 关键剧情不依赖广告、付费或排行榜。
- [ ] 文档中的“章”始终指 Campaign，不暗示塔层。
