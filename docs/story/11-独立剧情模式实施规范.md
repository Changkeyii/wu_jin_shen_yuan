# 独立剧情模式实施与台词规范

> 适用：Campaign「万灵记忆」。
> 本文不描述登塔故事门；登塔残响继续由现有 `StoryCatalog` 管理。

---

## 一、静态内容结构

建议 `CampaignCatalog`：

```lua
{
    id = "main:c01",
    title = "第一章·遗火门厅",
    order = 1,
    prerequisiteChapterId = nil,
    recommendedLevel = 3,
    stages = {
        {
            id = "main:c01:a",
            kind = "story",
            nodes = { ... },
            firstClearReward = { ... },
        },
        {
            id = "main:c01:b",
            kind = "battle",
            encounterId = "main:c01:battle:01",
            firstClearReward = { ... },
        },
        {
            id = "main:c01:c",
            kind = "boss",
            encounterId = "main:c01:boss",
            firstClearReward = { ... },
        },
    },
}
```

禁止出现：

```lua
floor = chapter * 10
unlockFloor = ...
GetChapterForFloor(...)
```

---

## 二、ID 约定

| 类型 | 格式 | 示例 |
|---|---|---|
| Campaign | `main` | `main` |
| Chapter | `main:cNN` | `main:c06` |
| Stage | `main:cNN:a/b/c` | `main:c06:b` |
| Node | `stageId:slug` | `main:c06:b:intro` |
| Encounter | `main:cNN:battle:NN` | `main:c06:battle:01` |
| Reward | `campaign:stage:<stageId>:first` | `campaign:stage:main:c06:c:first` |
| Choice | `main:choice:<slug>` | `main:choice:ending` |

发布后 ID 不得复用给其他内容。

---

## 三、服务器权威规则

服务端负责：

- Stage 是否解锁；
- 当前 Node；
- 对话行号；
- 剧情战斗敌人、血量、伤害和胜负；
- 首通、星级、重玩次数；
- 经验、金币、碎片、装备与材料；
- 章节完成；
- 剧情选择与结局资格；
- 断线恢复与奖励幂等。

客户端只提交稳定 ID 与操作意图，不上传胜利、奖励或数值。

---

## 四、经验曲线

剧情经验独立于塔层。建议每章经验总量：

```text
第 1–10 章：260 起，每章约增加 35
第 11–20 章：575 起，每章约增加 25
第 21–30 章：825 起，每章约增加 18
第 31–40 章：1005 起，每章约增加 15
```

Stage 分配：

| Stage | 本章经验占比 |
|---|---:|
| A · 调查 | 15% |
| B · 推进 | 40% |
| C · 决断 | 45% |

卷末 C Stage 可额外增加约 15%，最终应通过完整数值模拟校准，使主线完成约 Lv.35–38。

---

## 五、奖励政策

### 首通

- A：少量经验、金币、剧情档案；
- B：主要经验、金币、碎片、强化材料；
- C：主要经验、首通箱、章节档案；
- 卷末：许愿券、深渊票、按当前登塔品质解锁裁剪的定向成长箱，或剧情纪念物。

### 重玩

| 类型 | 奖励 |
|---|---|
| 纯剧情回放 | 无经济奖励 |
| 普通扫荡 | 小额经验、金币、基础材料，设置次数或收益衰减 |
| 回响挑战 | 星级与一次性挑战奖励 |
| 困难 Boss | 外观、称号、纪念物或有限材料 |

剧情重复挑战不得成为高于登塔与深渊的无限资源最优解。

### 广告

如未来给剧情结算增加激励广告，只能增加普通资源，并使用独立来源 `campaign_stage`。不能翻倍：

- 剧情档案；
- 结局条件；
- 角色选择；
- 关键装备；
- 唯一纪念物。

---

## 六、剧情战斗表现

- 守塔人相关敌人使用“战斗记录”“污染映像”“权限程序”等明确称谓。
- 胜利文案使用“记录已恢复”“权限已解除”“回响已归档”，避免“杀死万灵”。
- 剧情战斗失败不回退登塔层数，不丢失登塔战利品。
- 可提供塔灵援助、机制提示或临时教学构筑，但不修改登塔援助状态。

---

## 七、台词风格

### 塔灵

- 短、准确、不说谎。
- 无权回答时明确说“我不能”或“记录不允许”。
- 随主线推进逐渐使用“我”，但不变成普通人类。

### 守塔人 / 记录回响

- 只从个人经历发言。
- Boss 前提出价值冲突，不只说“打败我”。
- 记录与本人必须区分。

### 界门

- 像旧系统广播与未完成句子拼接。
- 不使用统治世界、享受痛苦等传统反派动机。

### 主角

- 使用第二人称“你”。
- 关键节点可让玩家选择当前态度，但不随意改写主线事实。
- 旧名不覆盖玩家昵称。

## 八、终局状态

```lua
campaign.endingChoice = {
    choiceId = "main:choice:ending",
    available = {
        seal = true,
        erase = true,
        witness = false,
    },
    selected = nil,
    confirmedAt = nil,
}
```

- 服务端计算可用结局；
- 不可逆选择二次确认；
- 无倒计时、无默认选项；
- 断线重连继续选择；
- 选择前可回看证词；
- 广告、付费、排行榜和真人社交不参与解锁。

---

## 九、实施批次

### 竖切

先实现第一卷五章：

- Campaign 状态全链路；
- 章节地图；
- 剧情对话；
- 独立战斗；
- 首通与扫荡；
- 市场、深渊、许愿、任务引导；
- 断线恢复与奖励幂等。

### 扩展

- 第二至第四卷：补齐前中期系统循环与 Lv.20 节点；
- 第五至第六卷：支线选择、困难挑战、旧约审判；
- 第七至第八卷：见证节点、结局资格与终局。

## 十、验收清单

- [ ] 剧情章/Stage/Node 无 `floor` 字段。
- [ ] 剧情通关不修改 `floor/maxFloor/position`。
- [ ] 剧情战斗不写 `currentMonster`。
- [ ] 剧情奖励不使用塔层公式与塔 pity。
- [ ] 市场等级限制仍由登塔进度决定。
- [ ] 深渊仍由账号等级和独立状态控制。
- [ ] 任务如统计剧情，使用 `campaign_*` 指标。
- [ ] 断线恢复当前对话或战斗。
- [ ] 首通奖励具有稳定幂等键。
- [ ] 推荐等级和战力是软提示。
- [ ] 主线与结局不依赖广告、付费、排行榜或真人社交。
