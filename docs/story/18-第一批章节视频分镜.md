## 1. 残刃开门 · `story_c01_open`

- **插入**：第 1 章 Stage A 开始前
- **时长**：8 秒
- **意象**：残刃 / 封存门

**画面：**
1. 0–2s 红发黑红机甲主角站在青紫霓虹塔廊，赤焰长枪刃低垂。
2. 2–5s 他抬起残缺枪刃，枪刃共鸣，六边形档案门亮起缝光。
3. 5–8s 镜头推向他的侧脸与门缝，塔灵青色全息残影在门后一闪。

**字幕：**
> 有些记录不在塔的高处。
> 它们只是被封存在无人再问起的地方。

**台词：**
```lua
dialogue = {

    { speaker = "塔灵", tone = "低语", text = "门会自己决定。走进去的人，是门在挑。" },
```

## 2. 空王座提问 · `story_c05_after`

- **插入**：第 5 章 Stage C 胜利后、奖励前
- **时长**：8 秒
- **意象**：空王座
- **成片**：`video/cgt-20260826201522-8f9p6_video.mp4`
- **首帧/插图**：`image/story_c05_illus_throne_1_20260826121409.png`

**画面：**
1. 0–3s 红发主角走进青紫霓虹议室，中央悬浮空座，权限环缺了一块。
2. 3–6s 他没有坐下，把赤焰枪刃横放在空座前。

## 6. 双向的手 · `story_c20_finale`

- **插入**：第 20 章 Stage C 后
- **时长**：10 秒
- **意象**：门两侧的灯（成片改为「护灯」意象，避开敏感判定）
- **成片**：`video/cgt-20260826203227-9hgh4_video.mp4`
- **首帧/插图**：`image/story_c20_illus_hand_2_20260826121506.png`

**画面：**
1. 0–3s 同一扇门的两侧被切开并置：左侧是尘乡灯火，右侧是灰白记忆界。
2. 3–7s 两侧各伸出一只手，几乎相触，中间隔着符文封条。
3. 7–10s 封条没有断。灯火一侧的手收回，去扶一盏将熄的灯；另一侧的手停在半空。

**字幕：**
> 关闭，是为了保住这边的灯。
> 关闭，也会让那边的人再没有归期。
> 方案没有失败。它只是被推迟了。

**台词：**
```lua
dialogue = {
    { speaker = "你", tone = "沉重", text = "封门那天，我替所有人做了决定。" },
    { speaker = "初代守塔人", tone = "平静", text = "你替世界守住了时间。可时间不会替你回答。" },
    { speaker = "塔灵", tone = "低语", text = "门的两侧，都有人在等你下一次选择。" },
},
```

**插图旁白：**

## 8. 两侧晨光 · `story_c40_finale`

- **插入**：第 40 章 Stage C 选择界面之前
- **时长**：12 秒
- **意象**：两侧晨光
- **成片**：`video/cgt-20260826203736-8hxwj_video.mp4`
- **首帧/插图**：`image/story_c40_illus_choice_1_20260826121431.png`

**画面：**
1. 0–4s 门缝第一次同时泄出两道晨光：一道暖黄，像尘乡灯火；一道冷白，像记忆界的档案光。
2. 4–8s 三道浅影在门前分开：一人守着灯，一人把名字投入门缝，一人把灯与签名分给两侧的人。
3. 8–12s 三道影停住，谁也不替观众走完。镜头只留下门、灯、空痕。

**字幕：**
> 被记住不是永不改变。
> 而是改变之后，仍有人愿意重新问你是谁。
> 选之前先看清：你会留下谁，又让谁等待。

**台词：**
```lua
dialogue = {
    { speaker = "塔灵", tone = "低语", text = "塔会记住你的答案。它不会替你承担答案。" },
    { speaker = "你", tone = "平静", text = "我知道。这一次，换我来签。" },
    { speaker = "弥娅", tone = "温和", text = "无论你选哪条路，尘乡的灯都会记得你。" },
```
