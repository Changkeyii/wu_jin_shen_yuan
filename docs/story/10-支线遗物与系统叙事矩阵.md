# 支线、遗物与系统叙事矩阵

> 适用：独立剧情 Campaign「万灵记忆」。
> 支线可增强人物理解、提供成长资源或解锁众证结局，但不绑定登塔层数。

---

## 一、支线分类

| 支线 | 承载系统 | 奖励 | 真结局关系 |
|---|---|---|---|
| 守塔人档案 | Campaign 回放 / 记忆挑战 | 人物证词、称号、材料 | 关键角色影响 |
| 五套遗物史 | 装备图鉴 / 剧情挑战 | 套装传说、定向材料 | 部分节点影响 |
| 尘乡来信 | 邮件 / 日常委托 | 世界变化、金币、碎片 | 主灯线影响 |
| 深渊归名 | 独立剧情挑战 / 深渊 | 归名档案、深渊材料 | 关键节点影响 |
| 见证关系 | NPC / 好友 / 宗门 | 双向证词、外观 | 必须有 NPC 替代路径 |
| 回响挑战 | 已通关剧情 Stage | 星级、纪念物、材料 | 不要求全三星 |

关键主线不能依赖广告、付费、排行榜名次或真人社交。

---

## 二、五套装备传说

每套装备采用三级叙事：

1. 单件残片：具体物件与使用者；
2. 部位拼图：武器、防具、首饰、特殊装备形成四段历史；
3. 整套真相：完成关键收集后解锁人物选择。

套装 lore 不以“达到某塔层”解锁；可由 Campaign 支线、图鉴收集、深渊掉落和装备发现共同推进。

### 2.1 绝望的噩梦·地狱之路

**人物**：洛恩。  
**主题**：死亡循环保存力量，却磨损继续战斗的理由。

| 部位组 | 故事 |
|---|---|
| 武器 | 洛恩第一次复活时在刃上刻下家人的名字。 |
| 防具 | 每次复活刻字都会少一笔，他便以伤痕补上。 |
| 首饰 | 同伴分别保存对洛恩的记忆，延缓其无名化。 |
| 特殊 | 罪孽记录器只记杀敌数，不记为何战斗，最终催生终末宿命。 |

关联：剧情第 25 章。

### 2.2 幸运三角·命运的骰子

**人物**：塞缪。  
**主题**：概率能计算风险，不能替人承担责任。

| 部位组 | 故事 |
|---|---|
| 武器 | 幸运刃偏向生存概率最高的路径。 |
| 防具 | 赌徒团队用装备分摊失败后果。 |
| 首饰 | 第七只手在结果揭晓前按住骰盅，提醒众人仍可退出。 |
| 特殊 | 不存在的第八面代表未被旧系统纳入计算的方案。 |

关联：剧情第 13、29 章。

### 2.3 永恒之旅·军神的隐秘

**人物**：赫铎、瑟安。  
**主题**：撤离与留下是同一场保护行动的两面。

| 部位组 | 故事 |
|---|---|
| 武器 | 远征终点的长枪从未抵达地图标注终点。 |
| 防具 | 不落旗帜是留给撤离者的方向标。 |
| 首饰 | 通讯记录保存赫铎违令前最后一次沉默。 |
| 特殊 | 终点钟响起时，一半军队入塔，一半护送名单前往尘乡。 |

关联：剧情第 2、14 章。

### 2.4 深渊窥视者·黑暗祭祀

**人物**：纳伊。  
**主题**：理解危险不等于认同或屈服于危险。

| 部位组 | 故事 |
|---|---|
| 武器 | 深渊獠牙是从界门边缘切下的固化协议。 |
| 防具 | 祭袍黑潮用于标记身份侵蚀速度。 |
| 首饰 | 亡者回声戒可分离合唱中的单个声音。 |
| 特殊 | 遗书保存纳伊为每个被识别声音留下的问题。 |

关联：剧情第 16、31、34 章。

### 2.5 古代祭祀·神圣预言

**人物**：伊莱娅。  
**主题**：预测不是命令，未来不能剥夺当下选择。

| 部位组 | 故事 |
|---|---|
| 武器 | 祭剑用于斩断被误写成宿命的注释。 |
| 防具 | 圣衣记录每一次预言偏差。 |
| 首饰 | 千魂祭戒保存自愿者撤回誓言的权利。 |
| 特殊 | 神谕终章保持空白，等待后来者选择。 |

关联：剧情第 26、30、40 章。

## 三、尘乡来信

### 弥娅

- 身份：尘乡主灯维护者，现世活人。
- 性格：务实、尖锐，不崇拜主角。
- 诉求：保护尘乡，拒绝让居民在不知情时成为下一批燃料。

### 来信阶段

| 剧情章 | 内容 |
|---:|---|
| 2 | 主灯首次求援，恢复补给线。 |
| 8 | 弥娅用真实故障讯号击破归乡幻象。 |
| 11–12 | 街道与门牌被遗忘。 |
| 19 | 主灯只剩九段有效符文。 |
| 30–33 | 尘乡提出知情、可撤回、非燃料化原则。 |
| 尾声 | 一封不承担系统功能的普通信。 |

关键剧情邮件不自动过期；奖励与正文分开，避免“未领资源 = 未读剧情”。

## 四、深渊归名

### 三档叙事

| 深渊 | 叙事表现 |
|---|---|
| 裂隙 | 词语缺失、名字模糊、物件尚可辨认 |
| 异变 | 多段记忆错误融合，矛盾场景并存 |
| 灾厄 | 高浓度门后投影与强身份侵蚀 |

### 归名流程

```text
发现重复声纹
→ 找到关联遗物
→ 区分混合记忆
→ 请求对方自述
→ 两个独立来源确认
→ 恢复临时边界
→ 本人选择留守、休眠或尝试回归
```

姓名恢复后对方拥有选择权；玩家不是捕获灵魂或替别人命名。

## 五、许愿池战斗映像

| 映像 | 原型 | 叙事定位 |
|---|---|---|
| 赤焰枪刃·战斗映像 | 第零见证者的记录武器 | 连击与记录 |
| 虚空壁垒·战斗映像 | 最初封门卫队协防记录 | 守御与反击 |
| 风暴猎手·战斗映像 | 尘乡外巡队追猎记录 | 速度与追击 |

映像可有战斗语音和有限人格表现，但不等于原型本人完整复活。

## 六、系统叙事边界

| 系统 | 叙事说明 | 与 Campaign 的关系 |
|---|---|---|
| 登塔 | 塔持续记录战斗与战利品 | 提供补强资源，不决定剧情解锁 |
| 离线收益 | 塔结算安全战斗样本 | 不随机触发关键剧情 |
| 死亡回层 | 登塔身份校验失败后回到本层起点 | 只属于登塔规则 |
| 强化 / 升星 | 将战斗结构重新压入装备 | Campaign 可引导真实操作 |
| 市场 | 尘乡与登塔者交换遗物使用权 | Campaign 提供安全教学订单 |
| 深渊 | 无名潮外溢与定向挑战 | Campaign 引导，实际状态独立 |
| 好友 / 宗门 | 双向见证与多人灯簇 | 可增强文本，不强制真人参与 |
| 排行榜 | 公开挑战记录 | 不决定人格价值或剧情结局 |
| 激励广告 | 可选额外资源 | 不进入世界观，不阻断主线 |

## 七、众证结局关键节点

真结局不要求全收集，但需要代表性完成：

1. 万灵意愿：阿妲与至少数位守塔人的重申意愿；
2. 尘乡灯网：弥娅主灯线；
3. 门后归名：至少一位归名者；
4. 协议伦理：三证议会与伪共识修正；
5. 历史责任：第零席与初代之答。

具体数量在 Campaign 实现时由服务端配置，不写入登塔状态。
