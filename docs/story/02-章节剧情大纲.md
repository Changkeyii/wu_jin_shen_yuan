# 独立剧情模式总索引 · 万灵记忆

> **核心边界**：剧情模式与登塔模式是两套独立玩法。
>
> - **剧情模式「万灵记忆」**：固定章节、固定关卡、剧情战斗、首通奖励和快速升级；只按前置剧情关卡解锁。
> - **登塔模式**：无尽刷宝、挂机、楼层推进、随机掉落与极限挑战；不决定剧情进度。
>
> 任何剧情章节都不得绑定 `floor`、`maxFloor`、塔房间或“到达第 X 层”。

---

## 一、模式定位

| 模式 | 玩家目标 | 核心产出 | 进度字段 |
|---|---|---|---|
| 万灵记忆 | 快速体验主线、学习系统、快速升级 | 稳定经验、金币、碎片、定向成长资源、剧情档案 | `campaignId / chapterId / stageId / nodeId` |
| 登塔 | 长期刷宝、追求极品、挑战更高难度 | 随机装备、挂机收益、塔里程碑 | `floor / maxFloor / position` |
| 深渊 | 定向材料与词缀挑战 | 深渊装备、碎片、进阶材料 | 独立 `abyss` 状态 |
| 市场 | 玩家经济与装备流通 | 交易收益、装备选择 | 独立市场状态 |
| 许愿 | 战斗映像收集与养成 | 映像、罐子、养成资源 | 独立 `wishPool` 状态 |

剧情会引导玩家体验登塔、深渊、市场和许愿，但**不会使用这些系统的进度作为主线硬门槛**。

## 四、章节关卡结构

每章默认包含三个核心 Stage；必要时可增加不影响主线的支线 Stage。

| Stage | 类型 | 时长目标 | 职责 |
|---|---|---:|---|
| A · 调查 | 剧情 / 探索 | 30–90 秒 | 建立场景、冲突与本章目标 |
| B · 推进 | 普通 / 精英战斗 | 45–90 秒 | 快速经验、玩法教学或机制练习 |
| C · 决断 | Boss / 选择 / 演出 | 60–150 秒 | 本章高潮、首通奖励、下一章解锁 |

每卷第 5 章的 C Stage 为卷级 Boss 或重大决断。

### 解锁规则

```text
完成序章
→ 解锁第一卷第一章
→ 通关本章 C Stage
→ 解锁下一章
```

允许显示推荐等级与推荐战力，但它们都是软提示。玩家可从登塔、剧情扫荡、深渊、任务、市场或养成中任选补强路径。

禁止：

```text
达到第 X 塔层才解锁剧情
剧情通关自动推进塔层
剧情 Boss 计入章节塔 Boss
剧情首通消耗塔掉落保底
```

## 五、成长目标

| 玩家阶段 | 剧情进度 | 目标等级 |
|---|---|---:|
| 完成序章 | Campaign 解锁 | Lv.3 左右 |
| 30 分钟 | 第一卷中段 | Lv.5–6 |
| 60–90 分钟 | 第二卷完成 | Lv.12–15 |
| 第四卷完成 | 中期系统成形 | Lv.20–22 |
| 第六卷完成 | 进入结局准备 | Lv.30–31 |
| 主线完成 | 转入长期玩法 | Lv.35–38 |

剧情负责稳定追赶，不直接保证 Lv.40；灾厄深渊和高阶成长仍由登塔、深渊与日常共同推进。

---

## 六、奖励原则

1. 剧情经验使用独立章节奖励表，由服务端调用通用经验发放逻辑。
2. 剧情金币、碎片与装备箱不按塔层计算。
3. 剧情装备是稳定追赶型奖励，不替代登塔的随机极品追求。
4. 不直接发 Epic / Myth 塔系装备。
5. 市场购买等级限制继续依据登塔进度，剧情升级不绕过限制。
6. 关键剧情、主线通关和结局不依赖广告、付费、排行榜或真人社交。
7. 激励广告可以用于额外资源，但不得阻断或翻倍关键剧情道具。
