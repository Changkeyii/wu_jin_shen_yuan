# 06 · 客户端网络与状态适配（ServerClient + GameStateAdapter）

> 客户端侧的两块骨架：
> - `ServerClient`：负责连接常驻服、收发命令、组包快照、监听分发。对外暴露 `On(name, handler)` 事件总线 + `Send(command, payload, cb)` 命令通道。
> - `GameStateAdapter`：**单向数据流核心**。维护权威态 `authoritative_` 与只读视图态 `view_`，快照/增量/事件都通过它落地，UI 只读 `GetViewState()`。

文件：
- `scripts/client/ServerClient.lua`（685 行）
- `scripts/client/GameStateAdapter.lua`（543 行）

## 1. ServerClient 对外 API

```lua
ServerClient.Start()                 -- 初始化：注册远程事件、连接常驻服、开始握手
ServerClient.Stop()                  -- 反注册、清空 pending/监听器
ServerClient.Update(dt)              -- 每帧：请求超时检测 + 同步超时检测
ServerClient.IsReady()               -- 是否已收到权威快照
ServerClient.On(name, handler)       -- 订阅事件，返回取消订阅函数
ServerClient.Send(command, payload, callback)  -- 发命令（带 requestId 与超时）
ServerClient.RequestSnapshot(cb)     -- 主动请求全量快照
```

### 1.1 事件总线

| 事件名 | 触发时机 | 载荷 |
|--------|---------|------|
| `"connected"` | 建立连接、开始同步 | `viewState` |
| `"status"` | 收到 STATUS 消息 | `{state, code, reason, ...}` |
| `"snapshotProgress"` | 快照分片进度 | `{received, total}` |
| `"snapshot"` | 完整快照已应用 | `viewState` |
| `"delta"` | 增量已应用 | `{state, events}` |
| `"ready"` | 进入 ready 态 | `viewState` |
| `"adminResult"` | 管理员操作结果 | `result` |
| `"error"` | 错误（含超时/断线/校验失败） | `{code, reason}` |
| `"disconnected"` | 断线 | `viewState` |
| `"response"` | 任意命令响应（低层） | `payload` |

```lua
function ServerClient.On(name, handler)
    assert(type(handler) == "function", "handler must be a function")
    listeners_[name] = listeners_[name] or {}
    local handlers = listeners_[name]
    handlers[#handlers + 1] = handler
    return function()   -- 返回取消订阅函数
        for index = #handlers, 1, -1 do
            if handlers[index] == handler then table.remove(handlers, index) end
        end
    end
end
```

### 1.2 发送命令

```lua
function ServerClient.Send(command, payload, callback)
    if not connection_ or not ready_ then
        local result = { ok=false, code=ErrorCodes.NOT_READY, reason="server snapshot not ready" }
        if callback then callback(result) end
        return nil, result.reason
    end
    local requestId = NewRequestId()          -- "c-<time>-<counter>"
    local ok, payloadJson = pcall(cjson.encode, payload or {})
    if not ok then ... return nil, "请求数据编码失败" end
    if #payloadJson > Protocol.MAX_PAYLOAD_BYTES then ... end

    local data = VariantMap()
    data[Protocol.FIELDS.REQUEST_ID] = Variant(requestId)
    data[Protocol.FIELDS.COMMAND] = Variant(command)
    data[Protocol.FIELDS.PAYLOAD_JSON] = Variant(payloadJson)
    if callback then pending_[requestId] = { callback=callback, command=command, elapsed=0, timeout=REQUEST_TIMEOUT_SECONDS } end
    local sent, sendReason = pcall(function() connection_:SendRemoteEvent(EVENTS.COMMAND, true, data) end)
    if not sent then pending_[requestId] = nil; ... return nil, sendReason end
    return requestId
end
```

**请求超时**：`Update` 每帧推进 `pending_[requestId].elapsed`，超 `REQUEST_TIMEOUT_SECONDS`（30s）用 `ErrorCodes.REQUEST_TIMEOUT` 回调用。

## 2. 快照分片组包（客户端）

服务端可能把全量快照拆成多个 chunk（每片约 56KB）。客户端 `HandleSnapshot` 按 `transferId + revision` 组装：

```lua
local function HandleSnapshot(eventType, eventData)
    local payload, reason = DecodePayload(eventData)
    if payload.chunkCount ~= nil then
        -- 校验 chunk 元数据（transferId/revision/chunkIndex/chunkCount/inventory 类型）
        ...
        if not snapshotAssembly_
            or snapshotAssembly_.transferId ~= transferId
            or snapshotAssembly_.revision ~= revision
        then
            snapshotAssembly_ = { transferId=transferId, revision=revision,
                chunkCount=chunkCount, received={}, chunks={}, snapshot=nil, events={} }
        end
        local assembly = snapshotAssembly_
        -- 首片携带 snapshot 元数据 + events
        if payload.snapshot then
            if chunkIndex ~= 1 or assembly.snapshot then return error end
            assembly.snapshot = payload.snapshot
            assembly.events = payload.events
        end
        if not assembly.received[chunkIndex] then
            assembly.received[chunkIndex] = true
            assembly.chunks[chunkIndex] = payload.inventory
        end
        -- 全部收齐 → 合并背包 → ApplyCompleteSnapshot
        local receivedCount = ...
        Emit("snapshotProgress", { received=receivedCount, total=assembly.chunkCount })
        if receivedCount < assembly.chunkCount or not assembly.snapshot then return end
        local inventory = {}
        for index = 1, assembly.chunkCount do
            for _, item in ipairs(assembly.chunks[index]) do inventory[#inventory+1] = item end
        end
        assembly.snapshot.inventory = inventory
        ApplyCompleteSnapshot(assembly.snapshot, assembly.events)
        return
    end
    ApplyCompleteSnapshot(payload.snapshot or payload, payload.events or {})
end
```

## 3. 增量处理与"回退全量"策略

`HandleDelta` 校验失败时**主动回退全量快照**，保证最终一致：

```lua
local function HandleDelta(eventType, eventData)
    ...
    local delta = payload.delta or payload
    local valid, validationError = GameStateSchema.ValidateDelta(delta)
    if not valid then
        Emit("error", { code=ErrorCodes.INVALID_STATE, reason=... })
        ServerClient.RequestSnapshot()   -- ← 增量不合法 → 请求全量
        return
    end
    if delta.revision <= GameStateAdapter.GetRevision() then return end  -- 旧增量丢弃
    local preparedEvents, eventReason = PrepareEventsForClient(delta.events or {})
    if not preparedEvents then Emit(...); ServerClient.RequestSnapshot(); return end
    local ok, applyReason = GameStateAdapter.ApplyDelta(delta)
    if not ok then Emit(...); ServerClient.RequestSnapshot(); return end
    Emit("delta", { state=GameStateAdapter.GetViewState(), events=delta.events or {} })
end
```

### 4.1 核心数据结构

### 4.3 增量合并 `ApplyDelta`

```lua
function GameStateAdapter.ApplyDelta(delta)
    if type(delta) ~= "table" then return false, "delta must be a table" end
    if delta.snapshot then return GameStateAdapter.ApplySnapshot(delta.snapshot) end
    if not authoritative_ then return false, "snapshot required before delta" end
    if delta.revision and authoritative_.revision and delta.revision <= authoritative_.revision then
        return true, view_   -- 旧增量直接忽略
    end

    local changes = DeepCopy(delta.changes or delta.changed or delta.state or {})
    -- 背包类字段单独处理（投影 + 替换）
    if changes.inventory ~= nil then authoritative_.inventory = ProjectInventory(changes.inventory); changes.inventory = nil end
    if changes.overflowLoot ~= nil then authoritative_.overflowLoot = ProjectInventory(changes.overflowLoot); changes.overflowLoot = nil end
    if changes.lootStash ~= nil then authoritative_.lootStash = DeepCopy(changes.lootStash); changes.lootStash = nil end
    if changes.equipped ~= nil then authoritative_.equipped = changes.equipped; changes.equipped = nil end
    if changes.stats ~= nil then authoritative_.stats = DeepCopy(changes.stats); changes.stats = nil end
    -- 其余标量字段深合并
    Merge(authoritative_, changes)
    -- 事件应用到权威态（推进怪物HP/玩家HP/日志等）
    ApplyEvents(authoritative_, delta.events)
    NormalizeStoryGate(authoritative_)
    RebuildView()
    return true, view_
end
```

### 4.4 视图重建 `RebuildView`

权威态 → 视图态：深拷贝 + 投影装备显示名 + 关联装备槽位 + 填充派生字段。

```lua
local function RebuildView()
    if not authoritative_ then view_ = EmptyView(); return view_ end
    local nextView = DeepCopy(authoritative_)
    nextView.page = page_
    nextView.connectionState = connectionState_
    nextView.readOnly = connectionState_ ~= "ready"
    nextView.nextExp = nextView.nextExp or math.floor(100 * (1.15 ^ (math.max(1, nextView.level or 1) - 1)))
    nextView.inventory = ProjectInventory(nextView.inventory or {})    -- 装备 → 带显示名的实例
    nextView.equipmentInventoryCount = #nextView.inventory
    -- 计算每件装备的 equippedSlot / isEquipped
    local byId = {}
    for _, item in ipairs(nextView.inventory) do byId[tostring(item.id)] = item end
    local equippedObjects = {}
    local equippedSlotByItemId = {}
    for slot, itemId in pairs(nextView.equippedSlots) do
        if type(itemId) == "table" then
            equippedObjects[slot] = itemId
        else
            equippedObjects[slot] = byId[tostring(itemId)]
            equippedSlotByItemId[tostring(itemId)] = slot
        end
    end
    for _, item in ipairs(nextView.inventory) do
        item.equippedSlot = equippedSlotByItemId[tostring(item.id)]
        item.isEquipped = item.equippedSlot ~= nil
    end
    nextView.equipped = equippedObjects
    view_ = nextView
    return view_
end
```

### 4.5 装备投影 `ProjectEquipment`

权威态里的装备实例合并 `EquipmentCatalog` 定义 + 权威 roll 数据，生成 UI 展示实体：

```lua
local function ProjectEquipment(item)
    if type(item) ~= "table" then return item end
    if not item.equipmentId then ... return projected end   -- 非装备道具
    local definition = EquipmentCatalog.Get(item.equipmentId)
    if not definition then ... return projected end
    local projected = DeepCopy(definition)
    -- V5 实例携带权威 roll 数值；definition 只是展示兜底，绝不覆盖服务端数据

    projected.level = item.level or definition.level
    projected.enhance = item.enhance or 0
    projected.star = item.star or 0
    projected.locked = item.locked == true
    projected.investedGold = ...
    projected.investedFragments = item.investedFragments or 0
    return projected
end
```

### 4.6 事件应用 `ApplyEvents`

事件不仅推日志，还会**更新权威态的当前怪物/玩家 HP/挂机状态**，保证视图与服务器一致：

```lua
local function ApplyEvents(state, events)
    state.logs = state.logs or {}
    for _, value in ipairs(events or {}) do
        local kind = value.kind
        if kind == "battle_won" or kind == "monster_defeated" then
            state.currentMonster = nil
        elseif kind == "battle_started" or kind == "monster_spawned" then
            -- 用事件里的 monster 信息重建 state.currentMonster
            state.currentMonster = monster
        elseif kind == "battle_hit" or kind == "damage_dealt" or kind == "player_attack_hit" then
            -- 更新 recentDamage + 怪物剩余 HP
        elseif kind == "player_damaged" then
            -- 更新玩家 HP
        elseif kind == "floor_reset" then state.room = 1; state.currentMonster = nil
        elseif kind == "story_gate" then state.pendingStoryGate = CopyStoryGate(value)
        elseif kind == "event_pending" then state.pendingEvent = { ... }
        elseif kind == "event_resolved" then state.pendingEvent = nil
        elseif kind == "equip_decision_applied" then state.pendingEquipDecision = nil
        end
        local text = EventText(value)
        if text then table.insert(state.logs, 1, text) end
    end
    while #state.logs > 40 do table.remove(state.logs) end   -- 日志上限 40
end
```

## 5. 连接状态机（客户端视角）

```
ServerClient.Start
   │  GameStateAdapter.Reset() → SetConnectionState("syncing")
   │  SubscribeToEvent(ServerReady / ServerConnected / ServerDisconnected)
   ▼
ServerConnected / ServerReady
   │  HandleConnected → BeginSync(connection)
   │     - 清理旧 pending
   │     - SendReady()（发 CLIENT_READY，带 protocolVersion）
   │     - Emit("connected")
   ▼
服务端回 STATUS(syncing) → STATUS(ready)
   │  HandleStatus → SetConnectionState + Emit("status")
   ▼
AbyssSnapshot 组包完成 → ApplyCompleteSnapshot
   │  - ValidateSnapshot
   │  - revision 去旧
   │  - GameStateAdapter.ApplySnapshot
   │  - ready_ = true, SetConnectionState("ready")
   │  - Emit("snapshot") → Emit("delta")（若带事件）→ Emit("ready")
   ▼
AbyssDelta 持续 → HandleDelta → ApplyDelta → Emit("delta")
```

超时兜底：`ServerClient.Update` 若 `syncElapsed_ >= 30s` 仍未 ready，`SetConnectionState("error")` + `Emit("error", NOT_READY 超时)`。

## 6. 复用要点
