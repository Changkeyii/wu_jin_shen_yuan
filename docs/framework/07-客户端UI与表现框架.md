# 07 · 客户端 UI 与表现框架（GameView + Theme + PlayPresentation）

> 客户端 UI 层基于 `urhox-libs/UI`（Yoga Flexbox + NanoVG），采用**声明式构建**。`GameView` 是入口与页面容器；`Theme` 是设计规范（配色/字体/稀有度/槽位/套装）；`PlayPresentation` 是横版战斗表现层（帧动画 + 卷轴 + 事件驱动）。

## 1. GameView 入口生命周期

```lua
function GameView.Start()
    graphics.windowTitle = CONFIG.Title
    LoadingController.Configure({ ... })      -- 加载屏（含快照进度）
    ConfigurePlayPresentation()               -- 把依赖注入 PlayPresentation（DI 风格）
    InitUI()                                   -- UI.Init({ theme=AppTheme, scale=CONFIG.ViewportScale })
    AudioController.Start()
    viewportWidth_, viewportHeight_ = graphics:GetWidth(), graphics:GetHeight()
    ProbeOptionalFonts()
    game = GameStateAdapter.GetViewState()
    BuildRoot()                                -- 构建 UI 根（三层 Zone）
    AudioController.SetPage(game.page)
    LoadingController.Start(uiRoot_)
    BindServerEvents()                         -- 订阅 ServerClient 事件 → 驱动 UI 刷新
    local ok, reason = ServerClient.Start()
    SubscribeToEvent("Update", function(eventType, eventData) GameView.HandleUpdate(eventType, eventData) end)
end

function GameView.Stop()
    UnsubscribeFromEvent("Update")
    PlayPresentation.Reset()
    CommonPromptDialog.Reset()
    DialogCoordinator.Clear(false)
    ItemTips.Stop()
    LoadingController.Stop()
    ServerClient.Stop()
    AudioController.Stop()
    UI.Shutdown()
end
```

每帧驱动（`HandleUpdate`）：

```lua
function GameView.HandleUpdate(eventType, eventData)
    local dt = eventData:GetFloat("TimeStep")
    ServerClient.Update(dt)                    -- 网络层（请求超时/同步超时）
    LoadingController.Update(dt)
    local state = GameStateAdapter.GetViewState()
    game = state
    if game.page == "play" then PlayPresentation.Update(dt) end
    if game.page == "frameEditor" then FrameEditorView.Update(dt) end
    -- 物理分辨率变化 → 全量重建
    if physicalWidth ~= viewportWidth_ or physicalHeight ~= viewportHeight_ then
        viewportWidth_, viewportHeight_ = physicalWidth, physicalHeight
        RequestFullRebuild()
    end
    if needsFullRebuild_ then needsFullRebuild_ = false; needsPageRefresh_ = false; BuildRoot()
    elseif needsPageRefresh_ then needsPageRefresh_ = false; RefreshCurrentPage() end
end
```

## 2. 页面系统（Page Router）

`GameView` 用 `GameStateAdapter.SetPage(pageId)` + `RefreshCurrentPage()` 做页面切换：

```lua
local function CreatePageContent()
    if game.page == "admin" and game.isAdmin then return AdminPanel.Build(UI, { onChanged=RequestPageRefresh, readOnly=game.readOnly }) end
    if game.page == "bag"       then return BuildInventoryPage() end
    if game.page == "codex"     then return EquipmentCodexView.Build { ... } end
    if game.page == "equip"     then ... return BuildEquipmentPage() end
    if game.page == "play"      then return PlayPresentation.BuildPage() end
    if game.page == "market"    then return CreateMarketPage() end
    if game.page == "frameEditor" then return BuildFrameEditorPage() end
    return CreateHomePage()     -- 默认首页
end

RefreshCurrentPage = function()
    if not pageContainer_ then RequestFullRebuild(); return end
    game = GameStateAdapter.GetViewState()
    pageContainer_:ClearChildren()
    pageContainer_:AddChild(CreatePageContent())
    UpdateTopBar()
    UpdateBottomNav()
end
```

**页面清单**：`home`（首页）、`play`（战斗）、`bag`（背包）、`equip`（装备）、`codex`（图鉴）、`market`（市场）、`admin`（管理）、`frameEditor`（动作帧编辑器）。

**全量重建 vs 页面刷新**：
- `RequestFullRebuild()`：重建 UI 根（`BuildRoot`）—— 分辨率变化、初始加载后。
- `RequestPageRefresh()`：只重建中间页内容（`RefreshCurrentPage`）—— 每次 Delta 后、切页后。

**服务器事件驱动刷新**（`BindServerEvents` 里的关键订阅）：

```lua
ServerClient.On("snapshot", function()
    game = GameStateAdapter.GetViewState()
    ...
    PlayPresentation.HandleSnapshot()   -- 重置战斗表现
    UpdateTopBar()
    if pageContainer_ then RefreshCurrentPage() else BuildRoot() end
    LoadingController.MarkSnapshotReceived()
end)
ServerClient.On("delta", function(payload)
    game = GameStateAdapter.GetViewState()
    ...
    PlayPresentation.HandleDelta(payload)   -- 事件驱动的战斗表现
    ShowDeltaFeedback(payload)
    UpdateTopBar()
    if game.page == "play" then PlayPresentation.Update(0)
    elseif game.page == "home" or "equip" or "bag" or "codex" then
        RequestPageRefresh()    -- 静态页每次增量后重建
    end
end)
ServerClient.On("status", function(payload) ... LoadingController.HandleStatus(state) ... end)
ServerClient.On("error", function(error) UI.Toast.Show(error.reason or "网络数据错误", {...}) end)
```

## 3. UI 根结构（BuildRoot）

三层锚定布局（顶部状态栏 / 中间页面 / 底部导航），配合 `UI.SafeAreaView` 适配刘海屏：

```
screenRoot_ (100% × 100%)
 ├── CreateBackground()              背景层
 └── safeContent (SafeAreaView, edges=top/bottom)
     └── verticalAnchorPlane (width=1080, height=100%)   ← 设计宽度锚定
         ├── topZone (absolute, top, height=310)     CreateTopBar()
         ├── middleZone (absolute, top=310, bottom=170)  pageContainer_（页面）
         └── bottomZone (absolute, bottom, height=170)   CreateBottomNav()
```

```lua
local function BuildRoot()
    game = GameStateAdapter.GetViewState()
    pageContainer_ = UI.Panel { id="middlePageContainer", width="100%", height="100%",
        overflow="hidden", children=initialPageChildren }
    -- topZone / middleZone / bottomZone 绝对定位（略）
    uiRoot_ = UI.Panel { id="verticalAnchorPlane", width=CONFIG.DesignW, height="100%",
        position="relative", overflow="hidden", children={ topZone, middleZone, bottomZone } }
    screenRoot_ = UI.Panel { id="screenRoot", width="100%", height="100%",
        backgroundColor=C.background, children={ CreateBackground(), safeContent } }
    UI.SetRoot(screenRoot_, true)
    -- 挂载全局弹窗/提示/加载层
    CommonPromptDialog.AttachRoot(screenRoot_)
    ItemTips.AttachRoot(screenRoot_)
    LoadingController.AttachRoot(uiRoot_)
end
```

> **设计宽度 1080，高度动态**：`CONFIG.ViewportScale()` = `physicalWidth / 1080`，`DynamicDesignHeight()` = `physicalHeight / scale`。顶部/中间/底部锚定占满任意竖屏比例，不做 letterbox。

## 7. PlayPresentation（战斗表现层）

### 7.1 依赖注入

`GameView.ConfigurePlayPresentation` 把渲染所需的一切注入 PlayPresentation（`UI`/`colors`/`assets`/`txt`/`formatInt`/`serverClient`/`loadingController`/动作参数/`rarityColor` 等）。PlayPresentation 不直接 require 这些依赖，只通过 `context_` 使用 —— 便于替换与测试。

### 7.2 表现核心：事件驱动

```lua
function PlayPresentation.HandleDelta(payload)
    local game = Game()
    local seenVisualEvents = {}     -- 去重（同一 attackSerial+hitIndex+damage 只播一次）
    local seenLootItems = {}
    for _, value in ipairs((payload and payload.events) or {}) do
        local kind = value.kind or value.type
        if kind == "cell_entered" then
            AlignCurrentRoadEvent(NormalizedEventType(value))       -- 卷轴前进
        elseif kind == "battle_started" or kind == "monster_spawned" then
            lastEventType_ = NormalizedEventType(value)
            currentEventLocked_ = true
            -- 记录怪物 HP（优先 BigNumber 字段）
            currentMonsterHp_ = value.monsterHpBig or value.hpBig or ...
        elseif kind == "attack_started" then
            SetCombatSequence(sequenceIndex, hitFrame, attackSerial, windupSeconds, recoverySeconds, endFrame)
        elseif kind == "battle_hit" or kind == "damage_dealt" or kind == "player_attack_hit" then
            if ShouldRenderVisual(seenVisualEvents, "enemy_hit", value) then
                ScheduleAttackDamageText(...)   -- 飘字
                TriggerCombatVisual(...)        -- 攻击动作
            end
        elseif kind == "player_damaged" then AddPlayerFeedback("-X", C().hp, "damage")
        elseif kind == "player_healed" then AddPlayerFeedback("吸血 +X", C().success, "heal")
        elseif kind == "floor_advanced" then BeginFloorTransition(...); ClearCombatPresentation(false)
        elseif kind == "boss_enraged" then AddEnemyDamageBurst("Boss 狂暴!", ...)
        elseif kind == "battle_won" or kind == "monster_defeated" then
            if currentEventLocked_ then rewardOrigin_ = {x=enemyX, y=enemyY} end  -- 掉落从怪物位置飞向背包
            currentMonsterHp_ = 0; AdvanceRoadEvent()
        elseif kind == "level_up" then AddPlayerFeedback("角色升级 Lv.X", C().focus, "level_up")
        elseif kind == "battle_reward" then ... 金币/经验文字
        elseif kind == "currency_drop" and value.currency == "gold" then 金币飞向金币栏
        elseif kind == "loot_dropped" then 装备掉落拾取动画（TriggerPickupVisual + 稀有度光柱）
        ...
    end
end
```

### 7.3 视觉事件去重

```lua
local function VisualEventKey(group, value)
    if value.eventId ~= nil then return group .. ":event:" .. tostring(value.eventId) end
    -- 用 serial + hitIndex + amount + remainingHp 组成指纹
    local serial = value.attackSerial or value.sequenceSerial or value.monsterAttackSerial
    local hitIndex = value.hitIndex or value.sequenceHitIndex
    local amount = value.amountBig or value.damageBig or value.amount or value.damage
    local remainingHp = value.targetHpBig or value.monsterHpBig or value.hpBig or ...
    return table.concat({group, tostring(serial or ""), tostring(hitIndex or ""),
        MagnitudeKey(amount), MagnitudeKey(remainingHp), tostring(value.source or "")}, ":")
end

local function ShouldRenderVisual(seen, group, value)
    local key = VisualEventKey(group, value)
    if key == nil then return true end
    if seen[key] then return false end
    seen[key] = true
    return true
end
```

> 去重原因：同一帧服务端可能下发多个结构等价的事件（网络重发/重复 tick），表现层需要保证"一次伤害只飘一次字、只播一次动作"。

## 8. UI 组件开发范式（新页面怎么加）

1. **写组件文件**，导出 `Build{...}` 工厂（如 `MarketView.Build`, `EquipmentCodexView.Build`）：
   ```lua
   local MarketView = {}
   function MarketView.Build(context)
       local game = context.game
       local items = game.marketListings or {}
       return UI.Panel { children = { UI.ScrollView { children = { ... } } } }
   end
   return MarketView
   ```
2. **在 `CreatePageContent` 注册页面分支**，传 `GameStateAdapter.GetViewState()` + 通用工具函数（`txt`/`formatInt`/`rarityColor`/`itemImage` 等）。
3. **数据刷新**：静态页面订阅 `ServerClient.On("delta", RequestPageRefresh)` 重建；战斗页面订阅 `PlayPresentation.HandleDelta` 做增量动画。
4. **通用工具从 GameView 注入**（Txt/CompactTxt/FormatInt/ImageProgress/ItemTips），不要在各组件重复实现。
