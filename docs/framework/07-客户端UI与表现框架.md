## 1. 架构模式：编排层 + View/Controller

```
GameView（编排层）
   ├── 启动时 Configure 所有 Controller（依赖注入）
   ├── 订阅 ServerClient 事件 → 分发刷新
   ├── CreatePageContent() 按 game.page 路由到对应 View.Build
   └── 每帧 HandleUpdate 驱动各 Controller.Update
        │
        ├── View（页面）       纯渲染：读 GameStateAdapter.GetViewState() 构建 UI 树
        │                     暴露 Build{...} / BuildPage() / Show() 工厂
        ├── Controller（交互）  业务动作：调 ServerClient.XXX + ActionResult + RequestPageRefresh
        └── Kit / ItemView     跨页面共享的通用工具（文本/进度条/装备展示）
```

**核心约定**：
1. **View 不直接调服务端**，通过 `context` 注入的 action 函数（由 Controller 提供）触发。
2. **Controller 不直接建 UI**，只编排：发命令 → 处理响应 → 触发刷新。
3. **所有依赖注入**：`GameView` 在启动时 `Configure{...}` 各 Controller/View，传入 `game`、`txt`、`rarityColor`、`itemImage`、`actionResult` 等。
4. **单向数据流**：`GameStateAdapter.GetViewState()` 是唯一数据源，View 只读它。

## 2. GameView 生命周期（编排层）

```lua
function GameView.Start()
    -- 1) 装配所有 Controller（依赖注入）
    NavigationController.Configure { refreshPage=..., isIdleRewardTracking=..., onPageChanged=... }
    GameplayDialogsController.Configure { actionResult=ActionResult }
    EquipmentUpgradePromptController.Configure { buildInventoryContext=..., actionResult=... }
    LootStashController.Configure { buildInventoryContext=..., equipItem=..., actionResult=... }
    DailyVipController.Configure { showActionResult=..., requestPageRefresh=..., hideItemTips=... }
    QuestController.Configure { requestPageRefresh=... }
    FaceSlapController.Configure { getGame=..., isBlocked=..., isEligible=..., showCampaign=... }
    OfflineClaimController.Configure { showActionResult=..., onLoginFlowCompleted=... }

    -- 2) 加载控制器 / 资源
    LoadingController.Configure({ ... })
    ConfigurePlayPresentation()      -- 注入战斗表现层依赖
    InitUI()                         -- UI.Init({ theme=AppTheme, scale=CONFIG.ViewportScale })
    AudioController.Start()

    -- 3) 构建 UI 根 + 绑定服务事件 + 启动网络
    BuildRoot()
    BindServerEvents()
    ServerClient.Start()
    SubscribeToEvent("Update", function(...) GameView.HandleUpdate(...) end)
end

function GameView.Stop()
    -- 逐个 Reset 各 Controller/View（PlayPresentation/CommonPromptDialog/DialogCoordinator/
    -- ItemTips/RewardFeedbackController/DailyVipController/FaceSlapController/
    -- NavigationController/EquipmentUpgradePromptController/LootStashController/
    -- LeaderboardController/LeaderboardDetailView/MailController/MailView/LoadingController）
    ServerClient.Stop()
    AudioController.Stop()
    UI.Shutdown()
end
```

每帧驱动（`HandleUpdate`）：网络层 → 加载层 → 各 Controller.Update → 战斗表现 → 分辨率变化全量重建：

```lua
function GameView.HandleUpdate(eventType, eventData)
    local dt = eventData:GetFloat("TimeStep")
    ServerClient.Update(dt)
    LoadingController.Update(dt)
    DailyVipController.Update(dt)
    FaceSlapController.Update(dt)
    MailController.Update(dt)
    if game.page == "play" then PlayPresentation.Update(dt) end
    if game.page == "frameEditor" then FrameEditorView.Update(dt) end
    if physicalWidth ~= viewportWidth_ or physicalHeight ~= viewportHeight_ then
        RequestFullRebuild()
    end
    if needsFullRebuild_ then BuildRoot() elseif needsPageRefresh_ then RefreshCurrentPage() end
end
```

## 3. 页面系统（NavigationController + CreatePageContent）

**页面清单**：`home`（首页）、`play`（战斗）、`bag`（背包）、`equip`（装备）、`codex`（图鉴）、`market`（市场）、`quest`（任务）、`frameEditor`（动作帧编辑器）、`admin`（管理）。

```lua
local function CreatePageContent()
    if game.page == "admin" and game.isAdmin then return AdminPanel.Build(UI, {...}) end
    if game.page == "bag"       then return BuildInventoryPage() end
    if game.page == "codex"     then return EquipmentCodexView.Build {...} end
    if game.page == "equip"     then ... return BuildEquipmentPage() end
    if game.page == "play"      then return PlayPresentation.BuildPage() end
    if game.page == "market"    then return CreateMarketPage() end
    if game.page == "quest"     then return QuestView.BuildPage() end
    if game.page == "frameEditor" then return BuildFrameEditorPage() end
    return HomeView.Build { game=game, onEnterPlay=..., onToggleAutoRun=...,
        onCollectOffline=..., onOpenDailyVip=... }   -- 默认首页
end

RefreshCurrentPage = function()
    if not pageContainer_ then RequestFullRebuild(); return end
    game = GameStateAdapter.GetViewState()
    pageContainer_:ClearChildren()
    pageContainer_:AddChild(CreatePageContent())
    UpdateTopBar()
    NavigationController.Update(game)   -- 底部导航高亮
end
```

页面路由统一走 `NavigationController.SwitchPage(pageId)`：

```lua
function NavigationController.SwitchPage(pageId)
    -- 离开 play 页时清理战斗表现；进入 play 页时先等战斗资源
    ...
end
function NavigationController.Build(game)   -- 构建底部导航栏
function NavigationController.Update(game)   -- 更新选中态
```

**全量重建 vs 页面刷新**：
- `RequestFullRebuild()` → `BuildRoot()`（分辨率变化、初始加载后）。
- `RequestPageRefresh()` → `RefreshCurrentPage()`（每次 Delta 后、切页后）。

## 4. UI 根结构（BuildRoot，重构后不变）

```
screenRoot_ (100% × 100%)
 ├── CreateBackground()              背景层
 └── safeContent (SafeAreaView, edges=top/bottom)
     └── verticalAnchorPlane (width=1080, height=100%)   ← 设计宽度锚定
         ├── topZone (absolute, top, height=LAYOUT.TOP_ZONE_HEIGHT)   TopBarView.Build
         ├── middleZone (absolute, top, bottom)                       pageContainer_（页面）
         └── bottomZone (absolute, bottom, height=LAYOUT.BOTTOM_ZONE_HEIGHT) NavigationController.Build
```

```lua
local function BuildRoot()
    game = GameStateAdapter.GetViewState()
    pageContainer_ = UI.Panel { id="middlePageContainer", ... }
    local topZone = UI.Panel { children={ TopBarView.Build(game, topRefs_) } }
    local middleZone = UI.Panel { children={ pageContainer_ } }
    local bottomZone = UI.Panel { children={ NavigationController.Build(game) } }
    uiRoot_ = UI.Panel { id="verticalAnchorPlane", width=CONFIG.DesignW, height="100%",
        children={ topZone, middleZone, bottomZone } }
    screenRoot_ = UI.Panel { children={ CreateBackground(), safeContent } }
    UI.SetRoot(screenRoot_, true)
    -- 挂载全局弹窗/提示/加载/邮件/排行榜详情
    LootStashController.AttachRoot(uiRoot_)
    EquipmentUpgradePromptController.AttachRoot(uiRoot_)
    CommonPromptDialog.AttachRoot(screenRoot_)
    ItemTips.AttachRoot(screenRoot_)
    LeaderboardDetailView.AttachRoot(screenRoot_)
    MailView.AttachRoot(screenRoot_)
    LoadingController.AttachRoot(uiRoot_)
end
```

## 6. Controllers（交互控制器模式）

每个 Controller 负责一块业务交互：**发命令 → 处理响应 → 刷新**。全部在 `GameView.Start` 里 `Configure{...}` 注入依赖。

| Controller | 职责 |
|-----------|------|
| `EquipmentActionController` | 装备动作封装：`EquipItem / UnequipSlot / AutoEquipBest / StrengthenSelected / StarSelected / DecomposeByFilter / SetEquipmentLock / SetInventoryPolicy / CollectOffline`（供各 View 复用，避免重复写命令调用） |
| `LootStashController` | 战利品箱：打开/领取/登录引导 |
| `OfflineClaimController` | 离线收益：预览/领取/登录引导流程 |
| `DailyVipController` | 每日 VIP：签到/广告奖励/红点 |
| `QuestController` | 任务：进度/领取 |
| `MailController` | 邮件：列表/红点/自动刷新 |
| `LeaderboardController` | 排行榜：拉取/详情/个性签名 |
| `RewardFeedbackController` | 奖励反馈：增量累计/弹窗/离线收益跟踪 |
| `FaceSlapController` | 引导弹窗调度：按优先级弹登录引导（离线收益/战利品箱/VIP），带缓存与阻塞判定 |
| `GameplayDialogsController` | 通用玩法弹窗：剧情/事件/塔规则/援助提示 |
| `EquipmentUpgradePromptController` | 换装升级提示弹窗 |

**Controller 典型结构**：

```lua
-- 以 EquipmentActionController 为例（由 GameView.Configure 注入依赖）
local EquipmentActionController = {}
local deps_ = {}

function EquipmentActionController.Configure(deps)
    deps_ = deps   -- { collectOffline, inventoryState, getGame, actionResult, requestPageRefresh }
end

function EquipmentActionController.StrengthenSelected(callback)
    local slot = deps_.inventoryState.selectedSlot
    if not slot then return end
    ServerClient.Strengthen(slot, function(result)
        deps_.actionResult(result, "强化成功")
        deps_.requestPageRefresh()
        if callback then callback(result) end
    end)
end

return EquipmentActionController
```

## 7. 服务器事件驱动刷新（BindServerEvents）

```lua
ServerClient.On("snapshot", function()
    RewardFeedbackController.SyncSnapshot()
    PlayPresentation.HandleSnapshot()
    UpdateTopBar()
    if pageContainer_ then RefreshCurrentPage() else BuildRoot() end
    LoadingController.MarkSnapshotReceived()
    FaceSlapController.Evaluate("snapshot")
end)
ServerClient.On("delta", function(payload)
    RewardFeedbackController.AccumulateDelta(payload)   -- 先累计奖励
    PlayPresentation.HandleDelta(payload)                -- 战斗表现
    RewardFeedbackController.PresentDelta(payload)       -- 奖励弹窗
    UpdateTopBar()
    if game.page == "play" then PlayPresentation.Update(0)
    elseif game.page in {home, equip, bag, codex} then RequestPageRefresh()
    end
end)
ServerClient.On("status", function(payload)
    -- 非 ready：Reset 各 Controller 连接态
    FaceSlapController.ResetConnection()
    DailyVipController.ResetConnection()
    OfflineClaimController.Reset()
    LootStashController.ResetConnection()
    PlayPresentation.CancelPendingAutoRun()
    LoadingController.HandleStatus(state)
end)
ServerClient.On("error", function(error) UI.Toast.Show(error.reason, {...}) end)
ServerClient.On("disconnected", function() ... end)
```

## 8. Theme（设计规范中心）

`Theme.lua` 是**单一设计数据源**：`CONFIG`（标题/设计宽度 1080）、`C`（颜色表）、`BrawlForgeTheme`（UI 主题扩展）、`RARITIES`（稀有度配色）、`SLOTS`（12 槽位）、`SETS`（五套装）、`EVENT_INFO`（事件类型配色）。各 View 从这里取色取尺寸，换风格只改这个文件。

```lua
local CONFIG = { Title="无尽深渊挂机录", designWidth=1080, designHeight=1920, StepSeconds=3.0, OfflineMaxSeconds=12*60*60 }
local C = { primary={31,162,255,255}, gold={255,198,26,255}, hp={245,50,45,255}, ... }
local BrawlForgeTheme = UI.Theme.ExtendTheme(UI.Theme.defaultTheme, { fonts, colors, radius(全直角), components={Button/Card/Modal/...} })
local RARITIES = { common/advanced/rare/artifact/legendary/epic/myth }
return { CONFIG, Colors=C, Theme=BrawlForgeTheme, Rarities, RarityOrder, Categories, Slots, SetOrder, Sets, EventInfo }
```

> 设计宽度 **1080，高度动态**：`CONFIG.ViewportScale() = physicalWidth / 1080`，`DynamicDesignHeight() = physicalHeight / scale`。顶部/中间/底部锚定占满任意竖屏比例。

## 9. PlayPresentation（战斗表现层）

重构后拆分出 `PlayWorldView`（横版卷轴世界）、`PlayHud`（战斗 HUD）、`PlayEffects`（特效），`PlayPresentation` 负责编排。核心仍是**事件驱动**：

```lua
function PlayPresentation.HandleDelta(payload)
    local seenVisualEvents = {}     -- 去重（同一 attackSerial+hitIndex+damage 只播一次）
    for _, value in ipairs((payload and payload.events) or {}) do
        local kind = value.kind or value.type
        if kind == "cell_entered" then AlignCurrentRoadEvent(NormalizedEventType(value))
        elseif kind == "battle_started" or kind == "monster_spawned" then
            currentEventLocked_ = true
            currentMonsterHp_ = value.monsterHpBig or value.hpBig or ...
        elseif kind == "attack_started" then
            SetCombatSequence(sequenceIndex, hitFrame, attackSerial, windupSeconds, recoverySeconds, endFrame)
        elseif kind == "battle_hit" or kind == "damage_dealt" then
            if ShouldRenderVisual(seenVisualEvents, "enemy_hit", value) then
                ScheduleAttackDamageText(...); TriggerCombatVisual(...)
            end
        elseif kind == "player_damaged" then AddPlayerFeedback("-X", C().hp, "damage")
        elseif kind == "floor_advanced" then BeginFloorTransition(...); ClearCombatPresentation(false)
        elseif kind == "battle_won" or kind == "monster_defeated" then
            if currentEventLocked_ then rewardOrigin_ = {x, y} end   -- 掉落从怪物位置飞向背包
            AdvanceRoadEvent()
        elseif kind == "battle_reward" then ...
        elseif kind == "loot_dropped" then TriggerPickupVisual(...)   -- 拾取动画 + 稀有度光柱
        end
    end
end
```

视觉事件去重指纹（防止重复飘字/重复动作）：

```lua
local function VisualEventKey(group, value)
    if value.eventId ~= nil then return group .. ":event:" .. tostring(value.eventId) end
    local serial = value.attackSerial or value.sequenceSerial or value.monsterAttackSerial
    local hitIndex = value.hitIndex or value.sequenceHitIndex
    local amount = value.amountBig or value.damageBig or value.amount or value.damage
    local remainingHp = value.targetHpBig or value.monsterHpBig or value.hpBig or ...
    return table.concat({group, tostring(serial or ""), tostring(hitIndex or ""),
        MagnitudeKey(amount), MagnitudeKey(remainingHp), tostring(value.source or "")}, ":")
end
```

## 10. UI 组件开发范式（新页面/新功能怎么加）

1. **View 文件**：`local XxxView = {}; function XxxView.Build(context) ... return UI.Panel{...} end; return XxxView`（纯渲染，读 `context.game`）。
2. **Controller 文件**（需要交互时）：`XxxController.Configure(deps)` 注入依赖，方法内 `ServerClient.XXX(cb)` + `ActionResult` + `RequestPageRefresh`。
3. **在 `CreatePageContent` 注册页面分支**（若新页面），或在现有页面把 Controller 的 action 传入 View。
4. **在 `GameView.Start` 里 `Configure{...}` 装配新 Controller**，`GameView.Stop` 里 `Reset()`。
5. **通用工具从 `Kit`/`ItemView`/`ViewAssets` 取**，不要在各 View 重复实现。
