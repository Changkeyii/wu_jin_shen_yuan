## 2. 客户端握手流程（状态机）

`ServerMain` 里用 `entry.metadata` + `FinalizeReady` + `FinalizeReadyAfterBroadcast` 实现多阶段握手，客户端状态依次：`syncing → (ready) → ready`：

```
ClientConnected        → registry_:OnConnected(connection)
ClientIdentity         → 解析 user_id → registry_:OnAuthenticated
                          → ResolvePlayerNickname(异步查 Tap 昵称)
ClientReady            → MarkClientReady（registry:MarkReady(connection, true)）
                          → FlushPendingStatuses → FinalizeReadyAfterBroadcast
FinalizeReadyAfterBroadcast
                          → mailService:DeliverBroadcasts（补发全服邮件，
                            保证首包快照的 mailSummary 红点已含新邮件）
                          → FinalizeReady
FinalizeReady          → 校验 nickname + session.generation
                          → profileService:MarkReady
                          → idleService:Reset
                          → adminService:ProcessInbox（处理离线期间 GM 指令）
                          → SendSnapshot（全量下发，含 mailSummary + 排行榜 Upsert）
                          → SendStatus(ready)
```

**关键：连接未 ready 前的状态排队**。`SendStatus` 在会话未 ready 时把 payload 缓存进 `entry.metadata.pendingStatuses`（最多 4 条），`FlushPendingStatuses` 在 ready 后补发：

```lua
local function SendStatus(connection, state, code, reason, extra)
    local payload = BuildStatusPayload(state, code, reason, extra)
    local entry = registry_ and registry_:GetByConnection(connection) or nil
    if not entry or not entry.ready then
        local terminal = state == "rejected" or state == "error" or state == "banned"
        if terminal then
            return SendPayload(connection, Protocol.EVENTS.STATUS, "Status", payload)
        end
        -- 非终态：排队等 ready 后补发
        entry.metadata = entry.metadata or {}
        entry.metadata.pendingStatuses = entry.metadata.pendingStatuses or {}
        local pending = entry.metadata.pendingStatuses
        pending[#pending + 1] = payload
        while #pending > 4 do table.remove(pending, 1) end
        return false
    end
    return SendPayload(connection, Protocol.EVENTS.STATUS, "Status", payload)
end
```

## 3. PlayerRegistry（玩家会话注册表）

职责：管理 **连接 ↔ 玩家** 的映射，维护会话"代际"（generation），处理顶号。

```lua
function PlayerRegistry.New(options)
    return setmetatable({
        _clock = options.clock or defaultClock,
        _connectionKey = options.connectionKey or defaultConnectionKey,
        _byUid = {},             -- uid → entry（当前活跃会话）
        _byConnection = {},      -- connection → entry
        _byConnectionKey = {},   -- tostring(connection) → entry（兼容别名）
        _generationByUid = {},   -- uid → 当前代际
    }, PlayerRegistry)
end
```

### 3.1 连接与认证

```lua
function PlayerRegistry:OnConnected(connection)
    -- 已存在则复用并登记别名，否则新建 entry
    local entry = { connection=connection, connectionKey=key,
        connectionAliases={ [connection]=true }, uid=nil, generation=0,
        authenticated=false, ready=false, superseded=false, isAdmin=false, metadata={} }
    ...
end

function PlayerRegistry:OnAuthenticated(connection, uid, nickname, attributes)
    local key = uidKey(uid)
    local entry = self:GetByConnection(connection) or self:OnConnected(connection)
    -- 顶号：旧 entry 标记 superseded + authenticated=false + ready=false
    local replaced = self._byUid[key]
    if replaced ~= nil and replaced ~= entry then
        replaced.superseded = true; replaced.authenticated = false; replaced.ready = false
    end
    -- 代际 +1（顶号后旧会话的所有异步回调因 generation 不匹配而失效）
    local generation = (self._generationByUid[key] or 0) + 1
    self._generationByUid[key] = generation
    entry.uid = uid; entry.generation = generation; entry.authenticated = true
    self._byUid[key] = entry
    return entry, replaced, replaced ~= nil
end
```

### 3.2 会话有效性判断（核心）

```lua
function PlayerRegistry:IsCurrent(entryOrConnection)
    local entry = ...
    return self._byUid[uidKey(entry.uid)] == entry            -- 是当前活跃 entry
        and self._generationByUid[uidKey(entry.uid)] == entry.generation  -- 代际匹配
        and not entry.superseded                               -- 未被顶号
end
```

> `IsCurrent` 是并发安全的关键：任何异步回调（云存储、离线结算、GM 队列）在执行前都会先 `IsCurrent` 检查，顶号后旧会话的挂起操作全部作废。

### 3.3 发送辅助

```lua
function PlayerRegistry:Send(uid, eventName, eventData)
    local entry = self:Get(uid)
    if entry == nil or not entry.ready or not self:IsCurrent(entry) then return false end
    local ok = pcall(function() entry.connection:SendRemoteEvent(eventName, true, eventData) end)
    return ok
end
```

## 4. CommandRouter（命令路由）

这是框架最核心的类。它把"命令注册 → 校验 → 鉴权 → 限流 → 串行 → 执行 → 响应"全部标准化。

### 4.1 命令定义结构

```lua
router:Register({
    name = "Game.Strengthen",          -- 命令名（NetworkProtocol 白名单）
    schema = { ... },                  -- payload 校验 Schema（NetworkProtocol 格式）
    rate = ServerConfig.RATES.Progression,  -- 限流规则（rateKey/rate）
    serialized = true,                 -- 是否走每玩家串行队列（默认 true）
    async = true,                      -- handler 是否异步完成（通过 done 回调）
    allowBeforeReady = false,          -- 是否允许会话 ready 前执行
    auth = nil,                        -- "admin" 需要管理员
    authorize = nil,                   -- 命令级鉴权钩子
    cacheResponse = true,              -- 是否缓存响应用于幂等重放
    handler = function(context, payload, done) ... end,
})
```

### 4.2 Dispatch 完整流程

```lua
function CommandRouter:Dispatch(connection, eventData)
    -- 1) 会话检查
    local entry = self._registry:GetByConnection(connection)
    if entry == nil or not entry.authenticated then
        return self:_sendError(connection, "", "", ErrorCodes.Make(ErrorCodes.UNAUTHENTICATED))
    end
    if not self._registry:IsCurrent(entry) then
        return self:_sendError(connection, "", "", ErrorCodes.Make(ErrorCodes.STALE_SESSION))
    end

    -- 2) 信封校验
    local validRequest, request, requestError = self._protocol.ReadCommandEvent(eventData)
    if not validRequest then return self:_sendError(connection, "", "", requestError) end

    -- 3) 命令查找 + ready 门槛
    local definition = self._definitions[request.command]
    if definition == nil then return self:_sendError(connection, request.requestId, request.command,
        ErrorCodes.Make(ErrorCodes.UNKNOWN_COMMAND)) end
    if not definition.allowBeforeReady and not entry.ready then
        return self:_sendError(connection, request.requestId, request.command, ErrorCodes.Make(ErrorCodes.NOT_READY))
    end

    -- 4) 幂等去重（requestId）
    local uidKey = tostring(entry.uid)
    local replayed, replayResult, replayStatus = self:_checkReplay(uidKey, connection, request)
    if replayed then return replayResult, replayStatus end

    -- 5) JSON 解码 + Schema 校验
    local decoded, payload, decodeError = self._protocol.DecodePayload(request.payloadJson, self._decodeJson)
    if not decoded then return self:_sendError(connection, request.requestId, request.command, decodeError) end
    local schemaOk, schemaError = self._protocol.ValidatePayload(payload, definition.schema)
    if not schemaOk then return self:_sendError(connection, request.requestId, request.command, schemaError) end

    -- 6) 鉴权（全局 authorize + 命令 authorize + auth=="admin"）
    local context = { uid=entry.uid, connection=connection, entry=entry,
        generation=entry.generation, requestId=request.requestId, command=request.command, router=self }
    local authorized, authError = self:_checkAuthorization(context, definition, payload)
    if not authorized then return self:_sendError(connection, request.requestId, request.command, authError) end

    -- 7) 限流
    local allowed, retryAfter = self._rateLimiter:Check(entry.uid, definition.rateKey or request.command, definition.rate)
    if not allowed then return self:_sendError(connection, request.requestId, request.command,
        ErrorCodes.Make(ErrorCodes.RATE_LIMITED, nil, { retryAfter = retryAfter })) end

    -- 8) 登记 pending + 执行（串行 or 直接）
    self:_setPending(uidKey, request, context)
    local cacheResponse = definition.cacheResponse ~= false
    local function finish(ok, result)
        return self:_finish(connection, uidKey, request, context.generation, ok, result, cacheResponse)
    end
    if definition.serialized then
        self._operationQueue:Enqueue(entry.uid, {
            async = true,
            run = function(queueDone)
                self:_execute(definition, context, payload, queueDone)
                return OperationQueueModule.PENDING
            end,
            onComplete = finish,
        })
    else
        self:_execute(definition, context, payload, finish)
    end
    return true, { queued = false }
end
```

### 4.3 幂等去重 `_checkReplay`

三种情况：
1. **缓存命中（同 requestId 同内容）**：直接返回缓存的响应（网络重发场景）。
2. **同 requestId 不同内容**：拒绝 `REQUEST_ID_REUSED`。
3. **pending 中（同 requestId 同内容）**：把该连接加入响应收件人，等执行完一起发。

```lua
function CommandRouter:_checkReplay(uidKey, connection, request)
    self:_pruneCache(uidKey)
    local cache = self._cache[uidKey]
    local cached = cache and cache.byId[request.requestId] or nil
    if cached ~= nil then
        if cached.command ~= request.command or cached.payloadJson ~= request.payloadJson then
            return true, self:_sendError(connection, request.requestId, request.command,
                ErrorCodes.Make(ErrorCodes.REQUEST_ID_REUSED))
        end
        self:_sendEnvelope(connection, cached.envelope)   -- 重放缓存
        return true, true, "replayed"
    end
    local pendingByUid = self._pending[uidKey]
    local pending = pendingByUid and pendingByUid[request.requestId] or nil
    if pending ~= nil then
        if pending.command ~= request.command or pending.payloadJson ~= request.payloadJson then
            return true, self:_sendError(connection, request.requestId, request.command,
                ErrorCodes.Make(ErrorCodes.REQUEST_ID_REUSED))
        end
        pending.connections[connection] = true            -- 加入收件人
        return true, true, "in_progress"
    end
    return false, nil
end
```

### 4.4 handler 三种完成形态

`_execute` 支持 handler 通过返回值或回调完成：

```lua
function CommandRouter:_execute(definition, context, payload, completed)
    ...
    local callOk, first, second = pcall(definition.handler, context, payload, handlerDone)
    if not callOk then handlerDone(false, ErrorCodes.Make(ErrorCodes.INTERNAL_ERROR, tostring(first)))
    elseif not finished then
        if first == CommandRouter.PENDING then
            return                                -- handler 异步，稍后调 done()
        elseif type(first) == "boolean" then
            handlerDone(first, second)            -- 同步返回 (ok, result)
        elseif first ~= nil then
            handlerDone(true, first)              -- 直接返回结果
        elseif definition.async ~= true then
            handlerDone(true, nil)                -- 同步无返回
        end
    end
end
```

### 4.5 响应封装 `responseBody`

统一把 handler 的返回值规范成 `{ok, code, reason, data}`：

```lua
local function responseBody(ok, value)
    if ok then
        if type(value) == "table" and value.ok == true then
            if value.code == nil then value.code = ErrorCodes.OK end
            return value
        end
        return ErrorCodes.Success(value)
    end
    if ErrorCodes.IsError(value) then return value end
    if type(value) == "table" and type(value.code) == "string" then
        return ErrorCodes.Make(value.code, value.reason, value.details)
    end
    if type(value) == "string" then return ErrorCodes.Make(ErrorCodes.OPERATION_FAILED, value) end
    return ErrorCodes.Make(ErrorCodes.OPERATION_FAILED)
end
```

## 5. RateLimiter（Token Bucket 限流）

```lua
function RateLimiter:Check(uid, action, rule, explicitCost)
    local normalized = normalizeRule(rule, explicitCost)
    if normalized == nil then return true, 0, math.huge end   -- 无规则不限制

    local playerKey = tostring(uid)
    local now = self._clock()
    local bucket = self._buckets[playerKey][action]
    if bucket == nil then
        bucket = { tokens = normalized.burst, lastRefill = now, ... }
    else
        -- 按时间补令牌
        local elapsed = math.max(0, now - bucket.lastRefill)
        bucket.tokens = math.min(normalized.burst, bucket.tokens + elapsed * normalized.refillRate)
        bucket.lastRefill = now
    end
    if bucket.tokens >= normalized.cost then
        bucket.tokens = bucket.tokens - normalized.cost
        return true, 0, bucket.tokens
    end
    -- 不足：计算 retryAfter
    local missing = normalized.cost - bucket.tokens
    local retryAfter = math.huge
    if normalized.refillRate > 0 then retryAfter = missing / normalized.refillRate end
    return false, retryAfter, bucket.tokens
end
```

## 6. OperationQueue（每玩家串行队列）

目的：同一玩家的所有状态变更**串行执行**，避免并发写覆盖；不同玩家并行。

```lua
function OperationQueue:Enqueue(uid, operation, onComplete)
    local run, async, callback = operationParts(operation, onComplete)
    local queue = self._queues[tostring(uid)]
    if queue == nil then queue = { items = {}, head = 1, runningJob = nil, draining = false } end
    local job = { id=nextId, run=run, async=async, onComplete=callback, finished=false }
    queue.items[#queue.items + 1] = job
    self:_drain(uidKey, queue)
    return job.id
end
```

**PENDING 语义**：job 的 `run(done)` 如果同步返回 `OperationQueue.PENDING`，表示它是异步的，稍后会调用 `done`。队列在 `_drain` 中看到 `PENDING` 就停止推进，等 `done` 触发 `_finish → _drain`。

```lua
local callOk, first, second = pcall(job.run, done, job.id)
if not callOk then done(false, ...)
elseif not job.finished then
    if first == OperationQueue.PENDING then
        -- 异步：等 done 稍后被调用
    elseif type(first) == "boolean" then done(first, second)
    elseif first ~= nil then done(true, first)
    elseif job.async == false then done(true, nil) end
end
```

> 注意：CommandRouter 与 IdleRuntimeService 都用这个队列串行化同玩家的挂机 tick 和玩家主动操作，保证 `state` 不被并发改坏。

## 8. 断线处理（客户端视角的收尾）

```lua
local function HandleClientDisconnected(eventType, eventData)
    local entry, wasCurrent = registry_:OnDisconnected(connection)
    if not wasCurrent or not entry.uid then return end
    profileService_:MarkDisconnected(entry.uid, entry.generation)
    idleService_:Remove(entry.uid)
    router_:Clear(entry.uid)                       -- 清缓存/pending/限流
    operationQueue_:Enqueue(entry.uid, function(done)
        profileService_:TouchAndDetach(entry.uid, entry.generation, function(result) done() end)
    end)   -- 排队写最后检查点（离线收益落库）
end
```
